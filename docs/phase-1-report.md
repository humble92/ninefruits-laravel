- 빈 DB에서 `setup:install --force --profile=korean-university`와 `setup:demo --size=small` 성공 확인
- CI(GitHub Actions)는 push 후 결과를 이 문서 7절에 기록

검토 중 발견해 고친 결함

- 포털 보안 화면에서 비밀번호 재확인이 필요할 때 확인 화면으로 보내면서도 작업(2단계 인증 등록/해제)이 그대로 실행되던 문제. 회귀 테스트 추가.

## 4. 구현 내용

| 영역 | 테이블 | 화면 | 비고 |
|---|---|---|---|
| 코드 데이터 | `lookup_types`, `lookup_values` | 코드 데이터(목록 + 값) | 시스템 목록: 민족, 입학 구분, 강의실 용도 |
| 국가, 언어 | `countries`, `languages` | 국가, 언어 | ISO 표준, 설치 언어로 이름 자동 입력 |
| 조직 | `org_unit_types`, `org_units`, `org_unit_successions`, `programs` | 조직 단위 유형, 조직 단위(개편 기능, 승계 목록), 프로그램 | 유효기간, 계층 함수, 순환 방지 트리거, 이름 다국어 검색 인덱스 |
| 시설 | `buildings`, `rooms` | 건물, 강의실 | 강의실 용도는 코드 데이터 |
| 학기 | `term_types`, `academic_years`, `terms`, `term_windows`, `time_slots` | 학기 종류, 학년도, 학기(상태 변경, 업무 기간), 교시 | 겹침 금지 배제 제약, 상태 전이 규칙, 대상 조건 |
| 교과/성적 | `course_categories`, `grade_scales`, `grade_scale_items` | 교과 구분, 성적 척도(등급) | 기본 척도 하나(부분 unique 인덱스) |
| 권한 | 권한 10개 추가 | 역할 할당의 범위 대상 선택(조직 단위, 프로그램) | 조직 단위 범위는 하위 조직 포함 |
| 공통 | — | — | `TargetCriteria`(대상 조건), 사용 중인 데이터 삭제 시 안내, 기관 시간대로 날짜/시각 표시와 입력 |

| 항목 | 계획 | 실제 | 이유 |
|---|---|---|---|
| 학생/교원/교과목 CSV | Phase 1 | Phase 2, 4 | 테이블 의존 관계 (개정 4에 반영) |

## 6. 발견해 고친 플랫폼 문제

- **시간대 저장 오류**: Laravel이 PostgreSQL에 날짜를 UTC 오프셋 없이 보내서, 기관 시간대로 만든 시각이 9시간 어긋나게 저장/비교되었다. 오프셋을 포함하는 연결 클래스로 수정([0006](decisions/0006-reference-data-model.md)).
- **관리 화면 시간대**: Filament가 시각을 UTC로 표시/입력받던 것을 기관 시간대로 설정. 날짜 표시는 ISO 형식(`2026-03-01`).
- **CSV 가져오기 중 DB 오류**: PostgreSQL에서는 한 행의 DB 오류가 묶음 전체를 실패시킨다. 행마다 세이브포인트를 두어 그 행만 실패로 기록.
