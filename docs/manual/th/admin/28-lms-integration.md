# 28. การเชื่อมต่อ LMS

เมนู: **การเชื่อมต่อ LMS > แพลตฟอร์ม LMS**, **การเชื่อมโยงรายวิชา**, **บันทึกการซิงค์** (สิทธิ์ `จัดการแพลตฟอร์ม LMS การเชื่อมโยง และการซิงค์` ค่าเริ่มต้น: เจ้าหน้าที่ฝ่ายวิชาการ นอกเหนือจากผู้ดูแลระบบและเจ้าหน้าที่ทะเบียน) อาจารย์ผู้สอนใช้ลิงก์ LMS ที่ **รายวิชาที่สอน** และในรายละเอียดกลุ่มเรียน และใช้ **ดึงคะแนนจาก LMS** ในหน้าจอกรอกเกรด การดึงคะแนนเป็นไปตามเงื่อนไขเดียวกับการกรอกเกรด (อาจารย์ผู้สอนภายในช่วงกรอกเกรด เจ้าหน้าที่ภายในขอบเขตการจัดการ `ผลการเรียน` ของตน)

รายละเอียดสำหรับนักพัฒนาอยู่ใน[คู่มือการเชื่อมต่อ LMS](../../../lms-integration-guide.md)

## ข้อมูลใดไปที่ใด

| SIS → LMS | เมื่อใด |
|---|---|
| กลุ่มเรียน (การสร้างรายวิชา) + อาจารย์ผู้สอน | เมื่อกลุ่มเรียน **เผยแพร่แล้ว** และด้วย `lms:sync` |
| การลงทะเบียนที่ยืนยันแล้ว → การเพิ่มสมาชิก | ทันทีเมื่อลงทะเบียน เลื่อนจากรายชื่อสำรอง หรือลงทะเบียนโดยเจ้าหน้าที่ |
| การลดรายวิชาหรือถอนรายวิชา → การนำสมาชิกออก | ทันที |
| การกระทบยอดทั้งหมด | ทุกวันเวลา 02:30 (`lms:reconcile`) |

| LMS → SIS | เมื่อใด |
|---|---|
| คะแนนสุดท้าย (ฉบับร่าง) | เมื่ออาจารย์ผู้สอนคลิก **ดึงคะแนนจาก LMS** ในหน้าจอกรอกเกรด อาจารย์ผู้สอนเป็นผู้บันทึกและส่งเอง |

เกรดที่ยืนยันแล้วจะไม่ถูกส่งไปยัง LMS เอกสารประกอบการสอน งานที่มอบหมาย และแบบทดสอบอยู่ใน LMS

## แพลตฟอร์ม

**แพลตฟอร์ม LMS**: รหัส ชื่อ ไดรเวอร์ URL หลัก ข้อมูลรับรอง (คีย์/ค่า จัดเก็บแบบเข้ารหัส คงค่าเดิมเมื่อเว้นว่างในการแก้ไข) ใช้งาน ซิงค์รายชื่อนักศึกษา ดึงคะแนนสุดท้าย

- ไดรเวอร์ **ไม่มี (บันทึกเท่านั้น)**: ไม่เรียกใช้สิ่งใด และบันทึกสิ่งที่จะถูกส่ง ใช้เพื่อตรวจสอบขั้นตอนหรือสาธิตก่อนการเชื่อมต่อจริง แพลตฟอร์ม `DEMO` ในข้อมูลสาธิตใช้ไดรเวอร์นี้
- `Moodle`, `Open edX`: ยังไม่มีตัวเชื่อมต่อ (ทำเครื่องหมายว่ายังไม่รองรับ) เมื่อเลือกใช้ การซิงค์จะถูกบันทึกว่าล้มเหลว
- การเปิด **ใช้งาน** จะทำให้การเผยแพร่กลุ่มเรียนและการเปลี่ยนแปลงการลงทะเบียนถูกส่งทันทีตั้งแต่นั้นไป และรวมแพลตฟอร์มไว้ในการกระทบยอดทุกคืน

## การเชื่อมโยงรายวิชาและบันทึกการซิงค์

- **การเชื่อมโยงรายวิชา**: กลุ่มเรียนใดเชื่อมโยงกับรายวิชาใดบนแพลตฟอร์ม (id, URL) สถานะ (รอดำเนินการ/เชื่อมโยงแล้ว/ล้มเหลว) การซิงค์ล่าสุดและข้อผิดพลาด **ซิงค์อีกครั้ง** จะส่งกลุ่มเรียน อาจารย์ผู้สอน และรายชื่อนักศึกษาอีกครั้ง
- **บันทึกการซิงค์**: ผลลัพธ์และข้อความของแต่ละขั้นตอน (รายวิชา เพิ่มและลบสมาชิก ดึงคะแนน กระทบยอด) ดูสาเหตุของความล้มเหลวได้ที่นี่
- คำสั่ง: `lms:sync {platform} --term={term}` (ส่งทั้งหมด, `--dry-run`), `lms:reconcile` (กระทบยอด)

## พอร์ทัล

- ลิงก์รายวิชาบนแพลตฟอร์มจะแสดงในรายละเอียดรายวิชาสำหรับนักศึกษาและอาจารย์ผู้สอน และในรายการ **รายวิชาที่สอน** ของอาจารย์ผู้สอน (เฉพาะกลุ่มเรียนที่เชื่อมโยงแล้ว)
- การกรอกเกรด: เมื่อเปิด **ดึงคะแนนสุดท้าย** สำหรับแพลตฟอร์มและกลุ่มเรียนเชื่อมโยงแล้ว ปุ่ม **ดึงคะแนนจาก LMS** จะปรากฏ ปุ่มนี้เพียงเติมคอลัมน์คะแนนและไม่บันทึก

## คำถามที่พบบ่อย

- **นักศึกษาไม่ปรากฏใน LMS** นักศึกษาต้องมีบัญชี (ผู้ใช้) จึงจะซิงค์ได้ หากไม่มี ให้ส่งคำเชิญ ([บทที่ 14](14-merge-and-invitations.md)) การกระทบยอดครั้งถัดไปจะเพิ่มนักศึกษาเข้าไป
- **การซิงค์ล้มเหลวอยู่ตลอด** อ่านข้อความในบันทึกการซิงค์ ข้อมูลรับรองหมดอายุเป็นสาเหตุที่พบบ่อย เปลี่ยนค่าในหน้าจอแก้ไขแพลตฟอร์มแล้ว **ซิงค์อีกครั้ง**
- **เราเปลี่ยนแพลตฟอร์ม** สร้างแพลตฟอร์มใหม่และปิด ใช้งาน ของแพลตฟอร์มเดิม การเชื่อมโยงจะสร้างแยกกันต่อแพลตฟอร์ม
