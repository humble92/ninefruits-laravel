# 23. หนังสือรับรอง

เมนู: **หนังสือรับรอง > หนังสือรับรองที่ออกแล้ว**, **ประเภทหนังสือรับรอง**, **การตั้งค่า > การตั้งค่าหนังสือรับรอง** หนังสือรับรองออกด้วยปุ่ม **ออกหนังสือรับรอง** ในหน้าจอระเบียนนักศึกษา (**นักศึกษาและบุคลากร > ระเบียนนักศึกษา > ดู**) นักศึกษาดาวน์โหลด PDF หนังสือรับรองของตนเองได้ในพอร์ทัลที่ **หนังสือรับรอง** ทุกคนสามารถตรวจสอบหนังสือรับรองได้ที่หน้า `/verify/{code}`

| สิทธิ์ | สิ่งที่ทำได้ |
|---|---|
| `ออก สร้างใหม่ และเพิกถอนหนังสือรับรอง` | ออก สร้างใหม่ เพิกถอน ดูหนังสือรับรองที่ออกแล้ว (ภายในขอบเขตการดูระเบียนนักศึกษา) |
| `จัดการประเภท แม่แบบ และการตั้งค่าหนังสือรับรอง` | ประเภทและแม่แบบของแต่ละภาษา รูปแบบเลขที่เอกสาร ผู้ลงนาม |

ค่าเริ่มต้นของบทบาท: เจ้าหน้าที่ออกหนังสือรับรองเป็นผู้ออก เจ้าหน้าที่ทะเบียนมีทั้งสองสิทธิ์ เจ้าหน้าที่ฝ่ายวิชาการจัดการประเภทและแม่แบบ

## ความแตกต่างจากระบบเดิม

- **ทะเบียนหนังสือรับรองที่ออก** ระบบเดิม (YUSTIC) พิมพ์โดยตรงจากหน้าจอ (`aca3/cti_*`) และทะเบียน (`SRCERT`) มีไว้เพียงเพื่อสร้างเลขที่ จึงไม่แสดงว่าใครเป็นผู้ออกหรือถูกเพิกถอนหรือไม่ ระบบใหม่บันทึกเลขที่เอกสาร รหัสตรวจสอบ เจ้าหน้าที่ วัตถุประสงค์ จำนวนฉบับ ไฟล์ PDF และค่า checksum ทุกครั้งที่ออก และหนังสือรับรองที่ถูกเพิกถอนยังคงมีแถวของตนอยู่
- **การตรวจสอบ** ระบบเดิมไม่มี หนังสือรับรองทุกฉบับมีรหัสตรวจสอบและ QR code และหน้าสาธารณะจะแสดงว่าออกแล้ว ประเภท วันที่ออก และผู้ถือแบบปิดบังบางส่วน (ตัวอักษรแรกและตัวสุดท้ายของนามสกุลและชื่อ ตัวเลข 4 หลักแรกของรหัสนักศึกษา)
- **แม่แบบ** ระบบเดิมมีสคริปต์ PDF แยกตามประเภทและภาษา ระบบใหม่แก้ไขแม่แบบของแต่ละภาษา (หัวเรื่อง เนื้อความ ท้ายเอกสาร ผู้ลงนาม) สำหรับแต่ละประเภทบนหน้าจอ
- **การระงับ** ระบบเดิมออกหนังสือรับรองโดยไม่คำนึงถึงรายชื่อห้ามลงทะเบียน ระบบใหม่ไม่ออกหนังสือรับรองให้นักศึกษาที่ถูกระงับการออกหนังสือรับรอง ([บทที่ 20](20-registration.md))
- ไม่มีการบันทึกค่าธรรมเนียม (ระบบเดิมบันทึกเพียงจำนวนเงิน)
- ไม่มีการยื่นคำขอออนไลน์โดยนักศึกษา (แผนการย้ายระบบ 17.5) เจ้าหน้าที่เป็นผู้ออกหนังสือรับรอง

## ประเภทและแม่แบบ

**ประเภทหนังสือรับรอง**: รหัส (ใช้ในเลขที่เอกสาร) ชื่อ (3 ภาษา) กลุ่มเป้าหมาย (ระเบียนนักศึกษาทุกรายการ / นักศึกษา / ผู้สำเร็จการศึกษา) มีผลการเรียน มีรูปถ่าย ใช้งาน ลำดับ โปรไฟล์มหาวิทยาลัยเกาหลีสร้างไว้ให้สามประเภท

| รหัส | ประเภท | กลุ่มเป้าหมาย | หมายเหตุ |
|---|---|---|---|
| `ENR` | หนังสือรับรองการเป็นนักศึกษา | นักศึกษา (ยังไม่สำเร็จการศึกษา) | |
| `GRD` | หนังสือรับรองการสำเร็จการศึกษา | ผู้สำเร็จการศึกษา | วันที่สำเร็จการศึกษา เลขที่ปริญญาบัตร |
| `TRN` | ใบแสดงผลการเรียน | ระเบียนนักศึกษาทุกรายการ | ตารางเกรดที่ยืนยันแล้วแยกตามภาคการศึกษา เกรดเฉลี่ยสะสม และหน่วยกิตที่ได้ |

**แม่แบบ** (ด้านล่างของหน้าจอแก้ไขประเภท): หนึ่งแม่แบบต่อภาษา หัวเรื่อง เนื้อความ (แยกย่อหน้าด้วยบรรทัดว่าง) ท้ายเอกสาร ผู้ลงนาม เนื้อความใช้ตัวแทนข้อมูลในวงเล็บปีกกา

| ตัวแทนข้อมูล | ค่า |
|---|---|
| `{institution}` | ชื่อสถาบัน (ในภาษานั้น) |
| `{student_name}`, `{student_number}` | ชื่อ (ในรูปแบบของภาษานั้น หากไม่มีจะใช้การสะกดแบบละติน) รหัสนักศึกษา |
| `{program}`, `{org_unit}` | หลักสูตร หน่วยงาน |
| `{admission_date}`, `{graduation_date}`, `{degree_number}` | วันที่เข้าศึกษา วันที่สำเร็จการศึกษา เลขที่ปริญญาบัตร |
| `{status}`, `{year_level}` | สถานภาพนักศึกษา ชั้นปี |
| `{birth_date}`, `{gender}`, `{nationality}` | วันเกิด เพศ สัญชาติ |
| `{issue_date}`, `{serial_number}`, `{purpose}`, `{copies}` | วันที่ออก เลขที่เอกสาร วัตถุประสงค์ จำนวนฉบับ |

วันที่จะพิมพ์ตามรูปแบบของภาษานั้น ค่าที่ไม่มี (เช่น วันที่สำเร็จการศึกษา) จะพิมพ์เป็นช่องว่าง ตารางข้อมูลส่วนบุคคล (ชื่อ รหัสนักศึกษา วันเกิด เพศ สัญชาติ หลักสูตร วันที่เข้าศึกษา ตามด้วยวันที่สำเร็จการศึกษาสำหรับผู้สำเร็จการศึกษา หรือสถานภาพและชั้นปีสำหรับกรณีอื่น) จะถูกเพิ่มโดยอัตโนมัติด้านบนเนื้อความ

## การตั้งค่า

**การตั้งค่า > การตั้งค่าหนังสือรับรอง**

- **รูปแบบเลขที่เอกสาร**: ค่าเริ่มต้น `{TYPE}-{YYYY}-{SEQ:6}` → `ENR-2026-000001` ต้องมี `{SEQ:n}` ลำดับจะนับแยกกันสำหรับแต่ละคำนำหน้าที่ต่างกัน `{TYPE}-{SEQ:6}` นับต่อประเภทข้ามปี `{YYYY}{SEQ:5}` นับต่อปีข้ามประเภท การออกพร้อมกันจะไม่ชนกัน (ตัวนับเพิ่มค่าแบบ atomic ในฐานข้อมูล)
- **ตรวจสอบได้เป็นเวลา (วัน)**: 0 หมายถึงตลอดไป หลังพ้นระยะเวลา หน้าตรวจสอบจะตอบว่า "หมดอายุ" ส่วนรายการที่ออกยังคงอยู่ในทะเบียน
- **ผู้ลงนามตามภาษา**: ชื่อที่พิมพ์เหนือตราประทับ ("อธิการบดี มหาวิทยาลัย Ninefruits") ผู้ลงนามในแม่แบบมีลำดับความสำคัญสูงกว่า

## การออกหนังสือรับรอง

**ออกหนังสือรับรอง** ในหน้าจอระเบียนนักศึกษา: ประเภท ภาษา วัตถุประสงค์ จำนวนฉบับ (1 ถึง 20) เมื่อบันทึก PDF จะเปิดในแท็บใหม่

ระบบจะปฏิเสธการออกเมื่อ:

- กลุ่มเป้าหมายของประเภทไม่ตรงกัน (หนังสือรับรองการเป็นนักศึกษาสำหรับผู้สำเร็จการศึกษา หนังสือรับรองการสำเร็จการศึกษาสำหรับนักศึกษาปัจจุบัน)
- ประเภทนั้นไม่ได้ใช้งาน
- ไม่มีแม่แบบสำหรับภาษานั้น
- นักศึกษามี **การระงับการออกหนังสือรับรอง** ที่มีผลอยู่ (การระงับ [บทที่ 20](20-registration.md)) ให้ยกเลิกการระงับก่อน
- ระเบียนนักศึกษาอยู่นอกขอบเขตการดู

การออกหนังสือรับรองจะถูกบันทึกในบันทึกการดำเนินงาน (`certificate.issued`: รหัสนักศึกษา ประเภท ภาษา เลขที่เอกสาร จำนวนฉบับ วัตถุประสงค์)

## หนังสือรับรองที่ออกแล้ว

**หนังสือรับรอง > หนังสือรับรองที่ออกแล้ว**: วันที่ออก เลขที่เอกสาร ประเภทและภาษา รหัสนักศึกษา ชื่อ วัตถุประสงค์ จำนวนฉบับ สถานะ เจ้าหน้าที่ กรองตามประเภทและสถานะได้ ขอบเขตการดูเหมือนกับของระเบียนนักศึกษา

- **PDF**: เปิดไฟล์ที่จัดเก็บไว้ ไม่มีการสร้างใหม่ จึงตรงกับฉบับที่ออกทุกประการ
- **หน้าตรวจสอบ**: เปิดหน้าสาธารณะ
- **สร้างใหม่**: สร้าง PDF ใหม่จากข้อมูลปัจจุบัน เช่น หลังแก้ไขแม่แบบ และแทนที่ไฟล์เดิม เลขที่เอกสารและรหัสตรวจสอบคงเดิม ค่า checksum จะเปลี่ยน เหตุการณ์ตรวจสอบ `certificate.rerendered` เหมือนกับคำสั่ง `certificate:render`
- **เพิกถอน**: ต้องระบุเหตุผล แถวและไฟล์ยังคงอยู่ สถานะเปลี่ยนเป็นเพิกถอนแล้ว และหน้าตรวจสอบจะตอบว่า "เพิกถอนแล้ว" เหตุการณ์ตรวจสอบ `certificate.revoked` หนังสือรับรองที่ถูกเพิกถอนจะไม่ถูกคืนสถานะ ให้ออกฉบับใหม่แทน

แถวในทะเบียนแก้ไขหรือลบบนหน้าจอไม่ได้

## การตรวจสอบ

- URL ตรวจสอบ (`/verify/{code}`) และ QR code จะพิมพ์ไว้ด้านล่างของหนังสือรับรอง รหัสเป็นสตริงสุ่มยาว 20 ตัวอักษร
- หน้านี้เปิดได้โดยไม่ต้องเข้าสู่ระบบ และจำกัดไว้ที่ 30 คำขอต่อนาที แสดงว่าหนังสือรับรองออกแล้วหรือไม่ ประเภท เลขที่เอกสาร วันที่ออก และชื่อและรหัสนักศึกษาแบบปิดบังบางส่วน รหัสที่ถูกเพิกถอน หมดอายุ และไม่รู้จัก จะได้รับคำตอบที่ต่างกัน
- หากต้องการตรวจสอบไฟล์ PDF ที่ได้รับมาโดยตรง ให้เปรียบเทียบค่า checksum (SHA-256) ในทะเบียนกับค่าแฮชของไฟล์ คำสั่ง `certificate:verify {code}` ก็ทำได้เช่นกัน

## พอร์ทัลนักศึกษา

**หนังสือรับรอง**: หนังสือรับรองที่ออกในระเบียนของนักศึกษาเอง พร้อม PDF หนังสือรับรองที่ถูกเพิกถอนจะแสดงในรายการพร้อมสถานะ แต่นักศึกษาจะดาวน์โหลด PDF ของหนังสือรับรองที่ถูกเพิกถอนไม่ได้ (เจ้าหน้าที่ผู้ออกสามารถเปิดเพื่อตรวจสอบบันทึกได้) ไฟล์ของนักศึกษาคนอื่นเปิดไม่ได้ (บังคับใช้ทั้งในแอปพลิเคชันและฐานข้อมูล)

## คำถามที่พบบ่อย

- **ชื่อสะกดผิด** แก้ไขรูปแบบชื่อของบุคคล (ในภาษานั้น) แล้ว **สร้างใหม่** หากส่งหนังสือรับรองไปแล้ว ให้เพิกถอนและออกฉบับใหม่
- **แก้ไขแม่แบบแล้ว หนังสือรับรองที่ออกไปแล้วจะเป็นอย่างไร** หนังสือรับรองเหล่านั้นไม่เปลี่ยนแปลง ให้ **สร้างใหม่** หากจำเป็น
- **เลขที่เอกสารถูกข้ามไป** เมื่อเกิดข้อผิดพลาดระหว่างการออก (เช่น บริการ PDF ไม่ทำงาน) เลขที่จะถูกใช้ไปแล้วและอาจไม่มีแถวในทะเบียนเหลืออยู่ ระบบรับประกันว่าเลขที่ไม่ซ้ำกัน แต่ไม่รับประกันว่าต่อเนื่องกัน
