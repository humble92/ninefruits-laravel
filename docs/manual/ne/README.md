# विद्यार्थी सूचना प्रणाली प्रयोगकर्ता पुस्तिका (नेपाली)

दैनिक रूपमा प्रणाली सञ्चालन गर्ने कर्मचारी तथा प्रणाली स्थापना, डिप्लोय र मर्मतसम्भार गर्ने IT सञ्चालकहरूका लागि। स्क्रिनहरू नेपालीमा उपलब्ध छन् (प्रयोगकर्ता मेनु > भाषा)।

अन्य भाषाहरू: [한국어](../ko/README.md), [English](../en/README.md), [简体中文](../zh_CN/README.md), [ລາວ](../lo/README.md), [Deutsch](../de/README.md), [Filipino](../fil/README.md), [Français](../fr/README.md), [日本語](../ja/README.md), [Монгол](../mn/README.md), [Bahasa Melayu](../ms/README.md), [Русский](../ru/README.md), [ไทย](../th/README.md), [Türkçe](../tr/README.md), [Oʻzbek](../uz/README.md), [Tiếng Việt](../vi/README.md)। कोरियाली संस्करण मूल स्रोत हो; अन्य संस्करणहरू मातृभाषी समीक्षाको प्रतीक्षामा रहेका अनुवाद हुन्।

## प्रशासक पुस्तिका

[admin/README.md](admin/README.md) — अध्याय 1 देखि 28 सम्म: सुरुवात, प्रयोगकर्ता र भूमिकादेखि संस्थाको सेटअप, भर्ना, विषय दर्ता, ग्रेड, प्रमाणपत्र, स्नातक र LMS एकीकरणसम्म।
