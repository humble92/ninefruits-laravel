# 1. Prise en main

## Se connecter

1. Ouvrez `/login` dans votre navigateur.
2. Saisissez votre adresse e-mail et votre mot de passe, puis appuyez sur **Se connecter**.
3. Si vous avez activé la double authentification, saisissez le code à 6 chiffres de votre application d’authentification ou le code reçu par e-mail.
4. Sur un ordinateur personnel, vous pouvez cocher **Mémoriser cet appareil**. Le code n’est alors plus demandé pendant la durée configurée (30 jours par défaut). Ne cochez pas cette option sur un ordinateur partagé.

Si vous avez oublié votre mot de passe, utilisez **Mot de passe oublié ?** sur l’écran de connexion pour recevoir un lien de réinitialisation. Des échecs de connexion répétés bloquent temporairement la connexion.

## Portail et panneau d’administration

| Écran | Adresse | Utilisateurs |
|---|---|---|
| Portail | `/portal` | Tous les utilisateurs. Mes informations, paramètres de sécurité. Les fonctions destinées aux étudiants et aux enseignants sont ajoutées dans les phases ultérieures |
| Panneau d’administration | `/admin` | Personnels disposant de l’autorisation `Ouvrir le panneau d’administration` |

Les deux écrans partagent la même connexion. Le menu utilisateur en haut à droite du panneau d’administration mène à **Double authentification** (paramètres de sécurité) et au **Portail**.

Le menu du panneau d’administration dépend de vos autorisations. S’il manque un menu, demandez une attribution de rôle à un administrateur système.

## Langue

Changez-la avec le sélecteur de langue en haut de l’écran. Si vous la changez une fois connecté, votre choix est enregistré sur votre compte et conservé pour vos prochaines connexions. L’administrateur système choisit les langues proposées sous **Paramètres > Établissement**.
