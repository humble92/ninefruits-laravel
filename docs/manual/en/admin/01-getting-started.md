# 1. Getting started

## Signing in

1. Open `/login` in your browser.
2. Enter your email and password and press **Sign in**.
3. If you have enrolled in two-factor authentication, enter the 6-digit code from your authenticator app or the code you received by email.
4. On a personal computer you can select **Remember this device**. The code is skipped for the configured period (30 days by default). Do not select it on a shared computer.

If you forgot your password, use **Forgot your password?** on the sign-in screen to receive a reset link. Repeated failed sign-ins temporarily block signing in.

## Portal and administration panel

| Screen | Address | Users |
|---|---|---|
| Portal | `/portal` | Every user. My details, security settings. Student and instructor features are added in later phases |
| Administration panel | `/admin` | Staff with the `Open the administration panel` permission |

Both screens share the same sign-in. The user menu at the top right of the administration panel links to **Two-factor authentication** (security settings) and to the **Portal**.

The administration panel menu depends on your permissions. If a menu is missing, ask a system administrator for a role assignment.

## Language

Change it with the language selector at the top of the screen. When you change it while signed in, the choice is saved on your account and kept for your next sign-in. The system administrator decides which languages are offered under **Settings > Institution**.
