# 1. Erste Schritte

## Anmelden

1. Öffnen Sie `/login` im Browser.
2. Geben Sie E-Mail-Adresse und Passwort ein und klicken Sie auf **Anmelden**.
3. Wenn Sie die Zwei-Faktor-Authentifizierung eingerichtet haben, geben Sie den 6-stelligen Code aus Ihrer Authenticator-App oder den per E-Mail erhaltenen Code ein.
4. An einem persönlichen Computer können Sie **Dieses Gerät merken** auswählen. Der Code entfällt dann für den eingestellten Zeitraum (standardmäßig 30 Tage). Wählen Sie diese Option nicht an einem gemeinsam genutzten Computer.

Wenn Sie Ihr Passwort vergessen haben, fordern Sie über **Passwort vergessen?** auf dem Anmeldebildschirm einen Link zum Zurücksetzen an. Wiederholt fehlgeschlagene Anmeldungen sperren die Anmeldung vorübergehend.

## Portal und Verwaltungsoberfläche

| Bildschirm | Adresse | Benutzer |
|---|---|---|
| Portal | `/portal` | Alle Benutzer. Eigene Angaben, Sicherheitseinstellungen. Funktionen für Studierende und Lehrpersonen kommen in späteren Phasen hinzu |
| Verwaltungsoberfläche | `/admin` | Personal mit der Berechtigung `Verwaltungsoberfläche öffnen` |

Beide Bildschirme verwenden dieselbe Anmeldung. Das Benutzermenü oben rechts in der Verwaltungsoberfläche führt zu **Zwei-Faktor-Authentifizierung** (Sicherheitseinstellungen) und zum **Portal**.

Das Menü der Verwaltungsoberfläche hängt von Ihren Berechtigungen ab. Fehlt ein Menü, bitten Sie die Systemadministration um eine Rollenzuweisung.

## Sprache

Ändern Sie die Sprache mit der Sprachauswahl oben auf dem Bildschirm. Wenn Sie sie im angemeldeten Zustand ändern, wird die Auswahl in Ihrem Konto gespeichert und bei der nächsten Anmeldung beibehalten. Welche Sprachen angeboten werden, legt die Systemadministration unter **Einstellungen > Hochschule** fest.
