# Manwal ng student information system (Filipino)

Para sa mga kawaning nangangasiwa ng sistema araw-araw at para sa mga IT operator na nag-i-install, nagde-deploy at nagme-maintain nito. Makukuha ang mga screen sa Filipino (menu ng user > wika).

Iba pang mga wika: [한국어](../ko/README.md), [English](../en/README.md), [简体中文](../zh_CN/README.md), [ລາວ](../lo/README.md), [Deutsch](../de/README.md), [Français](../fr/README.md), [日本語](../ja/README.md), [Монгол](../mn/README.md), [Bahasa Melayu](../ms/README.md), [नेपाली](../ne/README.md), [Русский](../ru/README.md), [ไทย](../th/README.md), [Türkçe](../tr/README.md), [Oʻzbek](../uz/README.md), [Tiếng Việt](../vi/README.md). Korean ang orihinal; ang ibang mga edisyon ay mga salin na naghihintay pa ng pagsusuri ng katutubong tagapagsalita.
