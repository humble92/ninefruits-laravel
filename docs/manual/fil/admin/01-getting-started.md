# 1. Pagsisimula

## Pag-sign in

1. Buksan ang `/login` sa iyong browser.
2. Ilagay ang iyong email at password at pindutin ang **Mag-sign in**.
3. Kung naka-enroll ka sa two-factor authentication, ilagay ang 6-digit na code mula sa iyong authenticator app o ang code na natanggap mo sa email.
4. Sa personal na computer, maaari mong piliin ang **Tandaan ang device na ito**. Lalaktawan ang code sa itinakdang panahon (30 araw bilang default). Huwag itong piliin sa computer na ginagamit ng marami.

Kung nakalimutan mo ang iyong password, gamitin ang **Nakalimutan ang password?** sa screen ng pag-sign in para makatanggap ng link sa pag-reset. Pansamantalang hinaharangan ang pag-sign in kapag paulit-ulit itong nabigo.

## Portal at panel ng administrasyon

| Screen | Address | Mga gumagamit |
|---|---|---|
| Portal | `/portal` | Lahat ng user. Aking mga detalye, mga setting ng seguridad. Idinadagdag sa mga susunod na phase ang mga feature para sa mag-aaral at instruktor |
| Panel ng administrasyon | `/admin` | Mga kawaning may pahintulot na `Buksan ang panel ng administrasyon` |

Iisa ang pag-sign in ng dalawang screen. Ang user menu sa kanang itaas ng panel ng administrasyon ay may link sa **Two-factor authentication** (mga setting ng seguridad) at sa **Portal**.

Nakadepende sa iyong mga pahintulot ang menu ng panel ng administrasyon. Kung may nawawalang menu, humiling ng pagtatalaga ng tungkulin sa isang administrator ng sistema.

## Wika

Palitan ito gamit ang pamili ng wika sa itaas ng screen. Kapag pinalitan mo ito habang naka-sign in, nase-save ang pinili sa iyong account at nananatili ito sa susunod mong pag-sign in. Ang administrator ng sistema ang nagpapasya kung aling mga wika ang iniaalok sa **Mga setting > Institusyon**.
