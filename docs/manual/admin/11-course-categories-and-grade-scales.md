# 11. 교과 구분과 성적 척도

## 교과 구분

메뉴: **기준정보 > 교과 구분** (`교과 구분 관리` 권한). 레거시 `SFOBJDIST`를 대신한다.

교양필수, 전공선택처럼 교과목을 나누는 기준이다. **상위**를 지정해 묶을 수 있다(예: 교양 → 교양필수, 교양선택). 졸업 요건(Phase 4, 11)에서 "전공필수 30학점"처럼 참조한다.

## 성적 척도

메뉴: **기준정보 > 성적 척도** (`성적 척도 관리` 권한). 레거시 `SSCOREDEF`를 대신한다.

| 척도 항목 | 설명 |
|---|---|
| 만점 평점 | 예: 4.5 |
| 기본 | 하나만 지정할 수 있다. 다른 척도를 기본으로 바꾸면 이전 기본은 자동으로 해제된다 |

척도를 열고 아래 **등급**에서 등급을 추가한다.

| 등급 항목 | 설명 |
|---|---|
| 등급 | 예: `A+`, `P` |
| 평점 | 평점 계산에 포함하는 등급은 필수 |
| 하한/상한(%) | 원점수 환산 기준(선택). 예: A+ 95~100 |
| 평점 계산 포함 | P/NP처럼 평점에 넣지 않는 등급은 끈다 |
| 이수 | F, NP처럼 학점을 받지 못하는 등급은 끈다 |
| 적용 과목 | 일반 과목(등급), P/F 과목(P, NP), 둘 다(예: I 미완). 성적 입력 화면은 과목의 성적 방식에 맞는 등급만 보여 준다 |

한국 대학 프로파일의 4.5 척도: A+ 4.5, A0 4.0, B+ 3.5, B0 3.0, C+ 2.5, C0 2.0, D+ 1.5, D0 1.0, F 0, P, NP.

레거시 YUST 프로파일(`yust-legacy`)은 4.3 척도를 기본으로 넣는다: A+ 4.3, A0 4.0, A- 3.7, B+ 3.3, B0 3.0, B- 2.7, C+ 2.3, C0 2.0, C- 1.7, D+ 1.3, D0 1.0, D- 0.7, F 0, P, N, I. 레거시 자료에 A+ 값이 없어 척도의 규칙에 따라 4.3으로 넣었다. 운영 전에 레거시 `SSCOREDEF`로 확인한다.

성적은 기본 척도로 입력하고, 입력할 때의 평점을 수강 기록에 함께 저장한다. 나중에 척도를 고쳐도 이미 준 성적의 평점은 바뀌지 않는다([21장](21-grades.md)).

이미 성적에 쓰인 척도는 지울 수 없다.
