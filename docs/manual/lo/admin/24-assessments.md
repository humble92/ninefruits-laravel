# 24. ການສອບເສັງ

ເມນູ: **ການສອບເສັງ > ຮອບສອບເສັງ**, **ຜົນສອບເສັງ**, **ປະເພດການສອບເສັງ**. ນັກສຶກສາລົງທະບຽນສອບ ແລະ ເບິ່ງຜົນໃນພອດທໍ **ການສອບເສັງ**.

| ສິດ | ສິ່ງທີ່ເຮັດໄດ້ |
|---|---|
| `ລົງທະບຽນນັກສຶກສາ, ປ້ອນ ແລະ ເຜີຍແຜ່ຜົນ, ບັນທຶກຜົນພາຍນອກ` | ລົງທະບຽນ·ຍົກເລີກ·ຂາດສອບຂອງນັກສຶກສາ, ປ້ອນຜົນ, ນຳເຂົ້າ CSV, ເຜີຍແຜ່ຜົນ, ບັນທຶກ·ລຶບຜົນພາຍນອກ, ເບິ່ງທະບຽນຜົນ (ພາຍໃນຂອບເຂດເບິ່ງບັນທຶກນັກສຶກສາ) |
| `ຄຸ້ມຄອງປະເພດການສອບເສັງ, ພາກສ່ວນ ແລະ ຮອບສອບເສັງ` | ປະເພດ ແລະ ພາກສ່ວນ, ສ້າງ·ແກ້ໄຂຮອບສອບເສັງ |

ຄ່າເລີ່ມຕົ້ນຂອງບົດບາດ: ພະນັກງານທະບຽນ ແລະ ພະນັກງານວິຊາການມີທັງສອງ.

## ສິ່ງທີ່ຕ່າງຈາກລະບົບເກົ່າ

- **ບໍ່ມີຖັນຕາຍຕົວຕໍ່ປະເພດ.** `CET` ຂອງລະບົບເກົ່າ (YUSTIC) ມີສີ່ຖັນຕາຍຕົວ ໄວຍາກອນ·ການຂຽນ·ການຟັງ·ການອ່ານ, ການສອບເສັງລວມ (`SSCORE_ADD`) ມີ P/N ໜຶ່ງຕົວອັກສອນຕໍ່ວິຊາ ແລະ ການສອບເສັງຄອມພິວເຕີ (`COMEXAM`) ເປັນອີກຕາຕະລາງໜຶ່ງ. ລະບົບໃໝ່ກຳນົດພາກສ່ວນ ແລະ ວິທີຕັດສິນໃນ **ປະເພດການສອບເສັງ** ແລະ ຈັດການທຸກການສອບເສັງດ້ວຍໂຄງສ້າງ ຮອບ·ການລົງທະບຽນ·ຜົນ ດຽວກັນ.
- **ການຕັດສິນຜ່ານ.** ລະບົບເກົ່າຜ່ານເມື່ອຜົນລວມສີ່ພາກສ່ວນເຖິງເກນ ແລະ ບໍ່ມີຄະແນນຂັ້ນຕ່ຳຕໍ່ພາກສ່ວນ. ລະບົບໃໝ່ຕັດສິນດ້ວຍຄະແນນຜ່ານຂອງປະເພດ (ຫຼື ຮອບ) ແລະ **ຄະແນນຂັ້ນຕ່ຳຕໍ່ພາກສ່ວນ**. ປະເພດຜ່ານ/ບໍ່ຜ່ານ ພະນັກງານເປັນຜູ້ຕັດສິນ.
- **ໄລຍະເວລາລົງທະບຽນ ແລະ ຈຳນວນຮັບ.** ລະບົບເກົ່າບໍ່ມີ. ຮອບມີເວລາເປີດ·ປິດລົງທະບຽນ ແລະ ຈຳນວນຮັບ.
- **ການເຜີຍແຜ່ຜົນ.** ລະບົບເກົ່ານັກສຶກສາເຫັນທັນທີທີ່ປ້ອນ ແລະ ເຫັນສະເພາະຮອບຫຼ້າສຸດ. ລະບົບໃໝ່ນັກສຶກສາເຫັນຫຼັງຈາກ **ເຜີຍແຜ່ຜົນ** ຂອງຮອບ ແລະ ຜົນຂອງທຸກຮອບຍັງຄົງຢູ່.
- **ຜົນພາຍນອກ.** ລະບົບເກົ່າບໍ່ມີບ່ອນບັນທຶກການສອບພາຍນອກ ເຊັ່ນ TOEFL, TOPIK (ຊ່ອງ HSK ໃນຕາຕະລາງກວດສອບການຈົບເປັນປ້າຍວ່າງ). ບັນທຶກຜົນພາຍນອກພ້ອມໄຟລ໌ຫຼັກຖານ.
- **ການເຊື່ອມໂຍງກັບເງື່ອນໄຂການຈົບການສຶກສາ.** ລະບົບເກົ່າຄົນເປັນຜູ້ເບິ່ງຕາຕະລາງກວດສອບການຈົບແລ້ວຕັດສິນ. ໃສ່ໃນຫຼັກສູດດ້ວຍປະເພດເງື່ອນໄຂການຈົບການສຶກສາ **ສອບເສັງຜ່ານ** ([ບົດທີ 17](17-courses-and-curriculum.md)).

## ປະເພດການສອບເສັງ ແລະ ພາກສ່ວນ

**ປະເພດການສອບເສັງ**: ລະຫັດ, ຊື່ (3 ພາສາ), ໝວດ (ພາສາ, ການສອບເສັງລວມ, ບົດຈົບຊັ້ນ, ການສອບພາຍນອກ), ວິທີໃຫ້ຄະແນນ, ຄະແນນເຕັມ, ຄະແນນຜ່ານ, ຜົນພາຍນອກ, ໃຊ້ງານ.

| ວິທີໃຫ້ຄະແນນ | ການປ້ອນ | ການຕັດສິນ |
|---|---|---|
| ຄະແນນ | ຄະແນນຕໍ່ພາກສ່ວນ (ຖ້າບໍ່ມີພາກສ່ວນ ແມ່ນຄະແນນລວມ) | ຄະແນນລວມ ≥ ຄະແນນຜ່ານ ແລະ ທຸກພາກສ່ວນ ≥ ຄະແນນຂັ້ນຕ່ຳຂອງພາກສ່ວນ. ຖ້າບໍ່ມີຄະແນນຜ່ານ ພະນັກງານເລືອກ |
| ຜ່ານ/ບໍ່ຜ່ານ | ຜ່ານຫຼືບໍ່ | ພະນັກງານເລືອກ |

**ພາກສ່ວນ** (ຢູ່ລຸ່ມໜ້າແກ້ໄຂປະເພດ): ລະຫັດ (ຊື່ຖັນໃນ CSV), ຊື່, ຄະແນນເຕັມ, ຄະແນນຂັ້ນຕ່ຳຂອງພາກສ່ວນ (ເລືອກໄດ້). ຖ້າມີພາກສ່ວນ ຄະແນນລວມຄືຜົນລວມຂອງຄະແນນພາກສ່ວນ.

ປະເພດທີ່ໂປຣໄຟລ໌ມະຫາວິທະຍາໄລເກົາຫຼີໃສ່ໄວ້:

| ລະຫັດ | ປະເພດ | ການຕັດສິນ | ໝາຍເຫດ |
|---|---|---|---|
| `ENG_COMP` | ການສອບເສັງພາສາອັງກິດລວມ | ຄະແນນ, ຜ່ານ 60 | ການຟັງ·ການອ່ານ·ການຂຽນ·ໄວຍາກອນ ຢ່າງລະ 25 ຄະແນນ |
| `COMP_EXAM` | ການສອບເສັງຄອມພິວເຕີລວມ | ຜ່ານ/ບໍ່ຜ່ານ | |
| `THESIS` | ບົດຈົບຊັ້ນ | ຜ່ານ/ບໍ່ຜ່ານ | |
| `TOPIK` | ການສອບວັດລະດັບພາສາເກົາຫຼີ | ຜ່ານ/ບໍ່ຜ່ານ, ພາຍນອກ | ບັນທຶກລະດັບ ແລະ ເລກທີໃບຢັ້ງຢືນ |

## ຮອບສອບເສັງ

**ຮອບສອບເສັງ**: ປະເພດ, ວັນທີສອບ (ບໍ່ຊ້ຳກັນພາຍໃນປະເພດ), ສະຖານທີ່, ຈຳນວນຮັບ, ເປີດ·ປິດລົງທະບຽນ, ຄະແນນຜ່ານ (ຖ້າປ່ອຍວ່າງ ໃຊ້ຄ່າຂອງປະເພດ). ຢູ່ລຸ່ມໜ້າແກ້ໄຂຮອບມີລາຍຊື່ **ຜູ້ລົງທະບຽນ**.

- **ລົງທະບຽນນັກສຶກສາ** (ປ້ອນລະຫັດນັກສຶກສາ): ພະນັກງານສາມາດລົງທະບຽນໃຫ້ໄດ້ຈົນເຖິງວັນທີສອບໂດຍບໍ່ຂຶ້ນກັບໄລຍະເວລາລົງທະບຽນ. ຈຳນວນຮັບຍັງນຳໃຊ້. ຮອບທີ່ວັນທີສອບຜ່ານໄປແລ້ວ ບໍ່ມີໃຜລົງທະບຽນໄດ້. ຜົນປ້ອນໄດ້ສະເພາະນັກສຶກສາທີ່ລົງທະບຽນແລ້ວ ແລະ ແຖວຂອງນັກສຶກສາທີ່ບໍ່ໄດ້ລົງທະບຽນໃນ CSV ຈະລາຍງານເປັນຂໍ້ຜິດພາດ ແລະ ຂ້າມ.
- ນັກສຶກສາລົງທະບຽນ·ຍົກເລີກໃນພອດທໍໃນໄລຍະເວລາລົງທະບຽນ. ສະເພາະນັກສຶກສາທີ່ກຳລັງຮຽນ ຫຼື ພັກການຮຽນເທົ່ານັ້ນ.
- **ປ້ອນຜົນ**: ຄະແນນຕໍ່ພາກສ່ວນ (ຫຼື ຄະແນນລວມ), ຜ່ານຫຼືບໍ່ຖ້າຈຳເປັນ, ໝາຍເຫດ. ກ່ອນເຜີຍແຜ່ ຖ້າປ້ອນອີກຄັ້ງ ຈະປ່ຽນ (ບັນທຶກການກວດສອບ `assessment.result_recorded`). **ຫຼັງເຜີຍແຜ່ຈະຖືກລັອກ** (ເບິ່ງຄຳຂໍແກ້ໄຂຂ້າງລຸ່ມ).
- **ຂາດສອບ**: ລົງທະບຽນແລ້ວແຕ່ບໍ່ໄດ້ເຂົ້າສອບ. ຖ້າປ້ອນຜົນ ຈະກັບໄປເປັນສະຖານະລົງທະບຽນແລ້ວ.
- **ຍົກເລີກການລົງທະບຽນ**: ການລົງທະບຽນທີ່ປ້ອນຜົນແລ້ວ ຍົກເລີກບໍ່ໄດ້.
- **ເຜີຍແຜ່ຜົນ**: ຕັ້ງແຕ່ຕອນນີ້ ນັກສຶກສາເຫັນຜົນຂອງຮອບນີ້. ຫຼັງເຜີຍແຜ່ ແກ້ໄຂ ຫຼື ລຶບຜົນໂດຍກົງບໍ່ໄດ້ ແຕ່ປ່ຽນດ້ວຍ **ຄຳຂໍແກ້ໄຂ** (ການຕັດສິນໃຈ 2026-10-23). ຄືກັບຄຳສັ່ງ `assessment:publish-results`.
- **ຄະແນນຜ່ານ** ຂອງຮອບ (ທັບຄ່າຂອງປະເພດ): ໃຊ້ເມື່ອການສອບຍາກ ແລະ ທີ່ປະຊຸມຕັດສິນຫຼຸດເກນ. **ກ່ອນເຜີຍແຜ່** ປ່ຽນໄດ້ ແລະ ທັນທີທີ່ປ່ຽນ ຜົນທີ່ປ້ອນແລ້ວຂອງຮອບນັ້ນຈະຖືກ **ຕັດສິນຄືນທັງໝົດ** ດ້ວຍຄະແນນທີ່ບັນທຶກໄວ້ (ຄະແນນລວມໃຊ້ເກນໃໝ່ ຄະແນນຂັ້ນຕ່ຳຂອງພາກສ່ວນໃຊ້ຄ່າຂອງປະເພດຄືເດີມ). ຖ້າໃສ່ເຫດຜົນ ບັນທຶກການກວດສອບ `assessment.pass_score_changed` ຈະບັນທຶກເກນກ່ອນ·ຫຼັງ ແລະ ລະຫັດນັກສຶກສາທີ່ຜົນການຕັດສິນປ່ຽນ. **ຫຼັງເຜີຍແຜ່** ຈະຖືກລັອກ (ສະເພາະຄຳຂໍແກ້ໄຂ). ຄະແນນຂັ້ນຕ່ຳຕໍ່ພາກສ່ວນປ່ຽນໃນຮອບບໍ່ໄດ້ (ການຕັ້ງຄ່າຂອງປະເພດ).
- **ນຳເຂົ້າຜົນ (CSV)**: ຮູບແບບຂ້າງລຸ່ມ. ແຖວຂອງນັກສຶກສາທີ່ບໍ່ໄດ້ລົງທະບຽນຈະຂ້າມເປັນຂໍ້ຜິດພາດ. ຄືກັບຄຳສັ່ງ `assessment:import-results`.

ຮູບແບບ CSV (ມີແຖວຫົວ, UTF-8):

| ຖັນ | ເນື້ອໃນ |
|---|---|
| `student_number` | ລະຫັດນັກສຶກສາ (ຈຳເປັນ) |
| ລະຫັດພາກສ່ວນ (`LISTENING`, …) | ຄະແນນພາກສ່ວນ. ບໍ່ແຍກຕົວພິມໃຫຍ່-ນ້ອຍ |
| `total` | ຄະແນນລວມສຳລັບປະເພດທີ່ບໍ່ມີພາກສ່ວນ |
| `passed` | `Y`/`N`. ຈຳເປັນສຳລັບປະເພດຜ່ານ/ບໍ່ຜ່ານ ຫຼື ປະເພດທີ່ບໍ່ມີຄະແນນຜ່ານ |
| `absent` | ຖ້າເປັນ `Y` ຈະຖືວ່າຂາດສອບ |
| `note` | ໝາຍເຫດ |

ແຖວທີ່ຜິດພາດຈະຖືກຂ້າມ ແລະ ລາຍງານພ້ອມເລກແຖວໃນການແຈ້ງເຕືອນຜົນ (ໜ້າຈໍ) ຫຼື ຜົນອອກ (ຄຳສັ່ງ).

## ຄຳຂໍແກ້ໄຂຜົນ

ຂັ້ນຕອນການປ່ຽນຜົນຂອງຮອບທີ່ເຜີຍແຜ່ແລ້ວ. ເປັນວິທີດຽວກັນກັບການແກ້ໄຂເກຣດ.

1. ກົດ **ຂໍແກ້ໄຂ** ໃນລາຍຊື່ຜູ້ລົງທະບຽນຂອງຮອບ: ຄະແນນໃໝ່ (ຫຼື ຜ່ານຫຼືບໍ່) ແລະ ເຫດຜົນ. ໜຶ່ງຜົນມີຄຳຂໍທີ່ລໍຖ້າໄດ້ພຽງໜຶ່ງ. ບັນທຶກການກວດສອບ `assessment.correction_requested`.
2. ທີ່ **ການສອບເສັງ > ການແກ້ໄຂຜົນ** ຜູ້ມີສິດ `ຄຸ້ມຄອງປະເພດການສອບເສັງ, ພາກສ່ວນ ແລະ ຮອບສອບເສັງ` ກົດ **ອະນຸມັດ** (ຄຳເຫັນເລືອກໄດ້) ຫຼື **ປະຕິເສດ** (ຕ້ອງໃສ່ຄຳເຫັນ). **ຕັດສິນຄຳຂໍຂອງຕົນເອງບໍ່ໄດ້.**
3. ທັນທີທີ່ອະນຸມັດ ຜົນຈະປ່ຽນເປັນຄ່າໃໝ່ ແລະ ສະແດງໃຫ້ນັກສຶກສາເຫັນ. ບັນທຶກການກວດສອບ `assessment.correction_approved`, `assessment.result_corrected`. ຜູ້ສົ່ງຄຳຂໍສາມາດຍົກເລີກຄຳຂໍໄດ້ຈົນກວ່າຈະຕັດສິນ.

ລາຍການສະແດງຄຳຂໍທີ່ລໍຖ້າເປັນຄ່າເລີ່ມຕົ້ນ ແລະ ສະແດງຄ່າປັດຈຸບັນ ແລະ ຄ່າທີ່ສະເໜີແກ້ໄຂຄຽງຄູ່ກັນ.

## ທະບຽນຜົນ

**ຜົນສອບເສັງ**: ທຸກຜົນ (ຮອບພາຍໃນ, ພາຍນອກ). ກັ່ນຕອງຕາມປະເພດ, ແຫຼ່ງທີ່ມາ, ຜ່ານຫຼືບໍ່. ຂອບເຂດເບິ່ງຄືກັບຂອບເຂດເບິ່ງບັນທຶກນັກສຶກສາ.

- **ບັນທຶກຜົນພາຍນອກ**: ລະຫັດນັກສຶກສາ, ປະເພດ (ສະເພາະປະເພດທີ່ຮັບຜົນພາຍນອກ), ວັນທີສອບ (ເປັນອະນາຄົດບໍ່ໄດ້), ຄະແນນລວມ, ລະດັບ, ຜ່ານຫຼືບໍ່, ເລກທີໃບຢັ້ງຢືນ, ໄຟລ໌ຫຼັກຖານ (PDF, JPG, PNG, 5MB), ໝາຍເຫດ. ບັນທຶກການກວດສອບ `assessment.external_recorded`.
- **ຫຼັກຖານ**: ເປີດໄຟລ໌. ນັກສຶກສາກໍເປີດຂອງຕົນໄດ້.
- **ລຶບ**: ຕ້ອງໃສ່ເຫດຜົນ, ບັນທຶກການກວດສອບ `assessment.result_removed`. ລຶບຜົນພາຍນອກທີ່ບັນທຶກຜິດ ຫຼື ຜົນກ່ອນເຜີຍແຜ່ ແລ້ວບັນທຶກໃໝ່. ຜົນຂອງຮອບທີ່ເຜີຍແຜ່ແລ້ວລຶບບໍ່ໄດ້ (ຄຳຂໍແກ້ໄຂ).

## ເງື່ອນໄຂການຈົບການສຶກສາ

ໃນການແກ້ໄຂ **ເງື່ອນໄຂການຈົບການສຶກສາ** ເລືອກປະເພດເງື່ອນໄຂ **ສອບເສັງຜ່ານ** ແລ້ວກຳນົດປະເພດການສອບເສັງ. ຖ້ານັກສຶກສາມີຜົນຜ່ານ (ພາຍໃນ ຫຼື ພາຍນອກ) ຂອງປະເພດນັ້ນແມ່ນແຕ່ໜຶ່ງລາຍການ ຖືວ່າຄົບເງື່ອນໄຂ. ເທິງພອດທໍ **ການສອບເສັງ** ສະແດງປະເພດທີ່ຫຼັກສູດຂອງນັກສຶກສາຕ້ອງການ ແລະ ຜ່ານຫຼືບໍ່. ການຕັດສິນການກວດສອບເງື່ອນໄຂຈົບການສຶກສາອ່ານເງື່ອນໄຂນີ້ໃນ Phase 11.

## ພອດທໍຂອງນັກສຶກສາ

**ການສອບເສັງ**: ເງື່ອນໄຂຂອງຫຼັກສູດ ແລະ ຜ່ານຫຼືບໍ່, ຮອບທີ່ເປີດລົງທະບຽນ (ລົງທະບຽນ·ຍົກເລີກ), ການລົງທະບຽນຂອງຂ້ອຍ, ຜົນຂອງຂ້ອຍ (ຮອບທີ່ເຜີຍແຜ່ແລ້ວ ແລະ ຜົນພາຍນອກ, ຄະແນນພາກສ່ວນ, ຫຼັກຖານ).

## ຄຳຖາມທີ່ພົບເລື້ອຍ

- **ບໍ່ແມ່ນໄລຍະເວລາລົງທະບຽນ ແຕ່ຕ້ອງລົງທະບຽນໃຫ້.** ພະນັກງານລົງທະບຽນໃຫ້ດ້ວຍ **ຜູ້ລົງທະບຽນ > ລົງທະບຽນນັກສຶກສາ** ຂອງຮອບ.
- **ຢາກປ່ຽນຄະແນນຜ່ານສະເພາະຮອບນີ້.** ປ້ອນຄະແນນຜ່ານຂອງຮອບ. ຜົນທີ່ປ້ອນໄປແລ້ວຕ້ອງປ້ອນອີກຄັ້ງຈຶ່ງຈະຕັດສິນດ້ວຍເກນໃໝ່.
- **ປ້ອນຄະແນນຜິດ.** ຖ້າກ່ອນເຜີຍແຜ່ **ປ້ອນຜົນ** ອີກຄັ້ງກໍປ່ຽນ. ຫຼັງເຜີຍແຜ່ ໃຫ້ສົ່ງ **ຄຳຂໍແກ້ໄຂ** ແລ້ວພະນັກງານຄົນອື່ນອະນຸມັດ.
- **ສະຖິຕິຜູ້ຂາດສອບ.** ກັ່ນຕອງລາຍຊື່ຜູ້ລົງທະບຽນຕາມສະຖານະ.
