# 28. ການເຊື່ອມຕໍ່ LMS

ເມນູ: **ການເຊື່ອມຕໍ່ LMS > ແພລດຟອມ LMS**, **ການເຊື່ອມຕໍ່ວິຊາ**, **ບັນທຶກການຊິງຄ໌** (ສິດ `ຄຸ້ມຄອງແພລດຟອມ LMS, ການເຊື່ອມຕໍ່ ແລະ ການຊິງຄ໌`, ຄ່າເລີ່ມຕົ້ນ: ນອກຈາກຜູ້ບໍລິຫານລະບົບ·ພະນັກງານທະບຽນແລ້ວ ຍັງມີພະນັກງານວິຊາການ). ອາຈານໃຊ້ລິ້ງ LMS ໃນ **ການສອນຂອງຂ້ອຍ** ແລະ ລາຍລະອຽດກຸ່ມຮຽນ ແລະ **ໂຫຼດຄະແນນຈາກ LMS** ໃນການປ້ອນເກຣດ. ການໂຫຼດມີເງື່ອນໄຂດຽວກັນກັບການປ້ອນເກຣດ (ອາຈານຜູ້ສອນພາຍໃນໄລຍະເວລາປ້ອນເກຣດ, ພະນັກງານພາຍໃນຂອບເຂດ `ຄຸ້ມຄອງເກຣດ`).

ລາຍລະອຽດສຳລັບນັກພັດທະນາຢູ່ທີ່ [ຄູ່ມືການເຊື່ອມຕໍ່ LMS](../../../lms-integration-guide.md).

## ອັນໃດໄປໃສ

| ລະບົບທະບຽນ → LMS | ເວລາ |
|---|---|
| ກຸ່ມຮຽນ (ສ້າງວິຊາ) + ອາຈານຜູ້ສອນ | ເມື່ອ **ເຜີຍແຜ່** ກຸ່ມຮຽນ ແລະ `lms:sync` |
| ຢືນຢັນການລົງທະບຽນ → ເພີ່ມສະມາຊິກ | ທັນທີທີ່ລົງທະບຽນຮຽນ·ເລື່ອນຂຶ້ນຈາກລາຍຊື່ລໍຖ້າ·ພະນັກງານດຳເນີນການລົງທະບຽນ |
| ຖອນ·ຖອນຕົວ → ເອົາສະມາຊິກອອກ | ທັນທີ |
| ການທຽບທັງໝົດ | ທຸກວັນ 02:30 (`lms:reconcile`) |

| LMS → ລະບົບທະບຽນ | ເວລາ |
|---|---|
| ຄະແນນສຸດທ້າຍ (ຮ່າງ) | ເມື່ອອາຈານກົດ **ໂຫຼດຄະແນນຈາກ LMS** ໃນການປ້ອນເກຣດ. ການບັນທຶກ·ສົ່ງເປັນໜ້າທີ່ຂອງອາຈານ |

ເກຣດທີ່ຢືນຢັນແລ້ວບໍ່ສົ່ງໄປ LMS. ເອກະສານການສອນ·ວຽກບ້ານ·ແບບທົດສອບຢູ່ໃນ LMS.

## ແພລດຟອມ

**ແພລດຟອມ LMS**: ລະຫັດ, ຊື່, ໄດຣເວີ, URL ພື້ນຖານ, ຂໍ້ມູນຢືນຢັນຕົວຕົນ (ຄີ/ຄ່າ, ເກັບແບບເຂົ້າລະຫັດ, ຖ້າປ່ອຍວ່າງຕອນແກ້ໄຂ ຈະຄົງຄ່າເດີມ), ໃຊ້ງານ, ຊິງຄ໌ລາຍຊື່ນັກສຶກສາ, ດຶງຄະແນນສຸດທ້າຍ.

- ໄດຣເວີ **ບໍ່ມີ (ບັນທຶກເທົ່ານັ້ນ)**: ບໍ່ເອີ້ນຫຍັງເລີຍ ພຽງບັນທຶກເນື້ອໃນທີ່ຈະສົ່ງ. ໃຊ້ເມື່ອກວດສອບຂັ້ນຕອນກ່ອນເຊື່ອມຕໍ່ ຫຼື ສາທິດ. ແພລດຟອມ `DEMO` ໃນຂໍ້ມູນເດໂມແມ່ນອັນນີ້.
- `Moodle`, `Open edX`: ຍັງບໍ່ມີຕົວເຊື່ອມຕໍ່ (ສະແດງວ່າຍັງບໍ່ໄດ້ພັດທະນາ). ຖ້າເລືອກ ການຊິງຄ໌ຈະຖືກບັນທຶກເປັນລົ້ມເຫຼວ.
- ເມື່ອເປີດ **ໃຊ້ງານ** ຕັ້ງແຕ່ນັ້ນການເຜີຍແຜ່ກຸ່ມຮຽນ·ການປ່ຽນແປງການລົງທະບຽນຈະຖືກສົ່ງທັນທີ ແລະ ຖືກລວມໃນການທຽບຕອນກາງຄືນ.

## ການເຊື່ອມຕໍ່ວິຊາ ແລະ ບັນທຶກການຊິງຄ໌

- **ການເຊື່ອມຕໍ່ວິຊາ**: ກຸ່ມຮຽນໃດເຊື່ອມຕໍ່ກັບວິຊາໃດຂອງແພລດຟອມ (ID, URL), ສະຖານະ (ລໍຖ້າ/ເຊື່ອມຕໍ່ແລ້ວ/ລົ້ມເຫຼວ), ການຊິງຄ໌ຄັ້ງຫຼ້າສຸດ ແລະ ຂໍ້ຜິດພາດ. **ຊິງຄ໌ອີກຄັ້ງ** ເພື່ອສົ່ງກຸ່ມຮຽນ·ອາຈານ·ນັກສຶກສາໄປໃໝ່.
- **ບັນທຶກການຊິງຄ໌**: ຜົນ ແລະ ຂໍ້ຄວາມຕໍ່ຂັ້ນຕອນ (ວິຊາ, ເພີ່ມ·ເອົາສະມາຊິກອອກ, ດຶງຄະແນນ, ທຽບ). ເບິ່ງສາເຫດຂອງຄວາມລົ້ມເຫຼວໄດ້ທີ່ນີ້.
- ຄຳສັ່ງ: `lms:sync {ແພລດຟອມ} --term={ພາກຮຽນ}` (ສົ່ງທັງໝົດ, `--dry-run`), `lms:reconcile` (ທຽບ).

## ພອດທໍ

- ລິ້ງວິຊາຂອງແພລດຟອມສະແດງໃນລາຍລະອຽດກຸ່ມຮຽນຂອງນັກສຶກສາ·ອາຈານ ແລະ ລາຍການການສອນຂອງອາຈານ (ສະເພາະກຸ່ມຮຽນທີ່ເຊື່ອມຕໍ່ແລ້ວ).
- ການປ້ອນເກຣດ: ຖ້າແພລດຟອມເປີດ **ດຶງຄະແນນສຸດທ້າຍ** ແລະ ກຸ່ມຮຽນເຊື່ອມຕໍ່ແລ້ວ ຈະມີປຸ່ມ **ໂຫຼດຄະແນນຈາກ LMS**. ຕື່ມສະເພາະຊ່ອງຄະແນນ ບໍ່ບັນທຶກ.

## ຄຳຖາມທີ່ພົບເລື້ອຍ

- **ນັກສຶກສາບໍ່ຢູ່ໃນ LMS.** ນັກສຶກສາຕ້ອງມີບັນຊີ (ຜູ້ໃຊ້) ຈຶ່ງຈະຊິງຄ໌ໄດ້. ຖ້າບໍ່ມີບັນຊີ ຫຼັງຈາກເຊີນ ([ບົດທີ 14](14-merge-and-invitations.md)) ຈະຖືກເພີ່ມໃນການທຽບຄັ້ງຕໍ່ໄປ.
- **ການຊິງຄ໌ຄ້າງເປັນລົ້ມເຫຼວ.** ເບິ່ງຂໍ້ຄວາມໃນບັນທຶກ. ຂໍ້ມູນຢືນຢັນຕົວຕົນໝົດອາຍຸເປັນສາເຫດທີ່ພົບເລື້ອຍ. ປ່ຽນຄ່າໃນການແກ້ໄຂແພລດຟອມ ແລ້ວ **ຊິງຄ໌ອີກຄັ້ງ**.
- **ປ່ຽນແພລດຟອມ.** ສ້າງແພລດຟອມໃໝ່ ແລະ ປິດການໃຊ້ງານຂອງແພລດຟອມເກົ່າ. ການເຊື່ອມຕໍ່ຖືກສ້າງແຍກຕາມແພລດຟອມ.
