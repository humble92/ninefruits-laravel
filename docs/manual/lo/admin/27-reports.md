# 27. ບົດລາຍງານ ແລະ ວິວ reporting

ເມນູ: **ບົດລາຍງານ > ບົດລາຍງານ** (ສິດ `ເບິ່ງ ແລະ ດາວໂຫຼດບົດລາຍງານມາດຕະຖານ`). ຄ່າເລີ່ມຕົ້ນຂອງບົດບາດ: ພະນັກງານທະບຽນ·ວິຊາການ, ຜູ້ຊ່ວຍພາກວິຊາ (ພາຍໃນຂອບເຂດ).

## ບົດລາຍງານມາດຕະຖານ

ເລືອກບົດລາຍງານ ແລະ ໃສ່ເງື່ອນໄຂ ຈະສະແດງໃນໜ້າຈໍເຖິງ 500 ແຖວ ແລະ ດາວໂຫຼດທັງໝົດດ້ວຍ **ດາວໂຫຼດ CSV** (UTF-8 BOM ເປີດໃນ Excel ໄດ້ທັນທີ). ການດາວໂຫຼດຖືກບັນທຶກໃນບັນທຶກການກວດສອບ `reports.exported`. ຄ່າທີ່ຂຶ້ນຕົ້ນດ້ວຍ `=`, `+`, `-`, `@` ຈະຖືກໃສ່ເຄື່ອງໝາຍວົງຢືມດ່ຽວ (`'`) ນຳໜ້າ ເພື່ອບໍ່ໃຫ້ Excel ແລ່ນເປັນສູດ.

| ບົດລາຍງານ | ເງື່ອນໄຂ | ເນື້ອໃນ |
|---|---|---|
| ລາຍຊື່ນັກສຶກສາ | ໜ່ວຍງານ (ລວມໜ່ວຍງານຍ່ອຍ), ສະຖານະ, ປີຮຽນ | ລະຫັດນັກສຶກສາ, ຊື່, ຫຼັກສູດ, ໜ່ວຍງານ, ປີຮຽນ, ສະຖານະ, ວັນທີເຂົ້າຮຽນ, ວັນທີຈົບ, ເລກທີປະລິນຍາ |
| ຈຳນວນນັກສຶກສາຕາມໜ່ວຍງານ·ຫຼັກສູດ·ປີຮຽນ·ສະຖານະ | ໜ່ວຍງານ, ສະຖານະ | ຈຳນວນນັກສຶກສາ |
| ສະຫຼຸບເກຣດພາກຮຽນ | ພາກຮຽນ, ສະຖານະທາງວິຊາການ | ໜ່ວຍກິດ ແລະ GPA ພາກຮຽນ·ສະສົມ, ຈຳນວນການເຕືອນທາງວິຊາການ, ອັນດັບນັກສຶກສາດີເດັ່ນ ([ບົດທີ 21](21-grades.md)) |
| ຜູ້ທີ່ຈະຈົບການສຶກສາ | ຄົບເງື່ອນໄຂຫຼືບໍ່ | ການກວດສອບເງື່ອນໄຂຈົບການສຶກສາຫຼ້າສຸດຕໍ່ນັກສຶກສາ·ຫຼັກສູດ ([ບົດທີ 26](26-graduation.md)) |
| ການປ່ຽນສະຖານະນັກສຶກສາ | ພາກຮຽນ, ໄລຍະເວລາ | ປະເພດການປ່ຽນ, ສະຖານະກ່ອນ·ຫຼັງ, ວັນທີມີຜົນ, ສະຖານະການດຳເນີນການ |
| ຈຳນວນລົງທະບຽນຕໍ່ກຸ່ມຮຽນ | ພາກຮຽນ, ໜ່ວຍງານ | ກຸ່ມຮຽນ, ອາຈານຜູ້ສອນ, ຈຳນວນຮັບ, ລົງທະບຽນແລ້ວ, ລໍຖ້າ |
| ນັກສຶກສາທີ່ບໍ່ໄດ້ລົງທະບຽນໃນພາກຮຽນ | ພາກຮຽນ, ໜ່ວຍງານ | ນັກສຶກສາທີ່ກຳລັງຮຽນທີ່ບໍ່ມີລາຍການລົງທະບຽນໃນພາກຮຽນນັ້ນ |

ຂອບເຂດທີ່ເຫັນຄືກັບຂອບເຂດສິດຂອງຜູ້ເບິ່ງ (ຂອບເຂດເບິ່ງບັນທຶກນັກສຶກສາ ແລະ ອື່ນໆ). ບົດລາຍງານຄ່າທຳນຽມ·ຄ່າຮຽນຂອງລະບົບເກົ່າ (YUSTIC) (ຄ້າງຊຳລະຄ່າຮຽນ ແລະ ອື່ນໆ) ຢູ່ນອກຂອບເຂດ ຈຶ່ງບໍ່ມີ.

## ວິວ reporting

ບົດລາຍງານອ່ານຈາກວິວໃນ schema `reporting` ຂອງ DB. ເຄື່ອງມື BI ຫຼື ຜູ້ໃຊ້ SQL ສອບຖາມວິວດຽວກັນດ້ວຍບົດບາດອ່ານຢ່າງດຽວ `app_reporting`.

| ວິວ | ເນື້ອໃນ |
|---|---|
| `reporting.students` | ບັນທຶກນັກສຶກສາ + ຊື່ບຸກຄົນ + ຊື່ຫຼັກສູດ·ໜ່ວຍງານ |
| `reporting.headcount` | ຈຳນວນນັກສຶກສາຕາມໜ່ວຍງານ·ຫຼັກສູດ·ປີຮຽນ·ສະຖານະ |
| `reporting.term_records` | ສະຫຼຸບເກຣດຕາມພາກຮຽນ |
| `reporting.course_grades` | ເກຣດຕໍ່ວິຊາ (ຢືນຢັນແລ້ວຫຼືບໍ່, ເກຣດ, ຜ່ານ, ການຮຽນຄືນ) |
| `reporting.section_enrollments` | ຈຳນວນລົງທະບຽນ·ລໍຖ້າຕໍ່ກຸ່ມຮຽນ, ອາຈານຜູ້ສອນ |
| `reporting.section_meetings` | ເວລາຮຽນ ແລະ ຫ້ອງຮຽນ |
| `reporting.status_changes` | ການປ່ຽນສະຖານະນັກສຶກສາ |
| `reporting.degree_audits` | ການກວດສອບເງື່ອນໄຂຈົບການສຶກສາຫຼ້າສຸດຕໍ່ນັກສຶກສາ·ບົດບາດຫຼັກສູດ |

- ຖັນທີ່ແປແລ້ວ (`program_name` ແລະ ອື່ນໆ) ຕາມ locale ຂອງຊ່ວງຮຽນ: `SET app.locale = 'ko';`. ມີຖັນ jsonb ຕົ້ນສະບັບ (`program_name_i18n` ແລະ ອື່ນໆ) ເຊັ່ນກັນ.
- ວິວເປັນ `security_invoker` ຈຶ່ງນຳໃຊ້ຄວາມປອດໄພລະດັບແຖວຂອງຜູ້ສອບຖາມຄືເດີມ. ຖ້າອ່ານດ້ວຍບັນຊີນັກສຶກສາ ຈະເຫັນສະເພາະແຖວຂອງຕົນ.
- ນິຍາມວິວຢູ່ທີ່ `database/sql/views/reporting.sql` ແລະ ຖ້າປ່ຽນ ໃຫ້ນຳໃຊ້ຄືນຈາກ migration.

ວິວ `AV_*` ຂອງລະບົບເກົ່າ (ປະມານ 90 ວິວ) ບໍ່ໄດ້ຖືກໃຊ້ ຈຶ່ງບໍ່ໄດ້ຍ້າຍມາ.
