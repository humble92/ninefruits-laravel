# 28. LMS 对接

菜单：**LMS 对接 > LMS 平台**、**课程关联**、**同步日志**（`管理 LMS 平台、关联和同步`权限，默认：除系统管理员、学籍管理员外还有教务管理员）。教师使用**我的授课**和班级详情中的 LMS 链接，以及成绩录入中的**从 LMS 导入分数**。导入的条件与成绩录入相同（任课教师在成绩录入期间内，教职员在`成绩管理`范围内）。

开发者详细说明见 [LMS 对接指南](../../../lms-integration-guide.md)。

## 什么数据流向哪里

| 教务 → LMS | 时点 |
|---|---|
| 开课班级（创建课程）+ 任课教师 | 班级**发布**时，以及 `lms:sync` |
| 选课确定 → 注册 | 选课、候补递补、教职员代选课后立即 |
| 退课、撤课 → 取消注册 | 立即 |
| 全量核对 | 每天 02:30（`lms:reconcile`） |

| LMS → 教务 | 时点 |
|---|---|
| 最终分数（草稿） | 教师在成绩录入中点击**从 LMS 导入分数**时。保存和提交由教师完成 |

已确定的成绩不会发送到 LMS。教学资料、作业、测验都在 LMS 内。

## 平台

**LMS 平台**：代码、名称、驱动、基础 URL、凭据（键/值，加密存储，编辑时留空则保留）、是否启用、同步选课名单、拉取最终分数。

- 驱动**无（仅记录）**：不调用任何接口，只记录将要发送的内容。用于对接前检查流程或演示。演示数据中的 `DEMO` 平台就是这种。
- `Moodle`、`Open edX`：连接器尚未实现（显示尚未实现）。选择后同步会记录为失败。
- 开启**启用**后，课程发布和选课变动即时传送，并成为每夜核对的对象。

## 课程关联与同步日志

- **课程关联**：哪个开课班级关联到哪个平台课程（ID、URL）、状态（待处理/已关联/失败）、最近同步和错误。用**重新同步**重新推送班级、教师和学生。
- **同步日志**：按步骤（课程、添加和移除成员、拉取分数、核对）的结果和消息。失败原因在这里查看。
- 命令：`lms:sync {平台} --term={学期}`（全量推送，`--dry-run`）、`lms:reconcile`（核对）。

## 门户

- 学生和教师的班级详情以及教师的我的授课列表中显示平台课程链接（仅已关联的班级）。
- 成绩录入：平台开启了**拉取最终分数**且班级已关联时，显示**从 LMS 导入分数**按钮。只填充分数栏，不保存。

## 常见问题

- **学生不在 LMS 中。** 学生必须有账户（用户）才能同步。没有账户时，邀请后（[第 14 章](14-merge-and-invitations.md)）在下一次核对时添加。
- **同步一直显示失败。** 查看日志中的消息。凭据过期很常见。在平台编辑中更改值后**重新同步**。
- **更换了平台。** 创建新平台并关闭旧平台的启用。关联按平台分别生成。
