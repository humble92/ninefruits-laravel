# 27. 보고서와 reporting 뷰

메뉴: **보고서 > 보고서**(`표준 보고서 조회와 내려받기` 권한). 역할 기본값: 학적·교무 담당, 학과 조교(범위 안).

## 표준 보고서

보고서를 고르고 조건을 넣으면 화면에 500행까지 보이고, **CSV 내려받기**로 전체를 받는다(UTF-8 BOM, 엑셀에서 바로 열림). 내려받기는 감사 `reports.exported`에 남는다. `=`, `+`, `-`, `@`로 시작하는 값은 엑셀에서 수식으로 실행되지 않도록 앞에 작은따옴표(`'`)를 붙여 내보낸다.

| 보고서 | 조건 | 내용 |
|---|---|---|
| 학생 명단 | 조직(하위 포함), 상태, 학년 | 학번, 성명, 과정, 조직, 학년, 상태, 입학일, 졸업일, 학위번호 |
| 조직·과정·학년·상태별 인원 | 조직, 상태 | 인원 수 |
| 학기 성적 요약 | 학기, 학사 상태 | 학기·누계 학점과 평점, 학사경고 횟수, 성적우수 순위([21장](21-grades.md)) |
| 졸업 예정자 | 충족 여부 | 학생·과정별 최신 졸업 요건 점검([26장](26-graduation.md)) |
| 학적 변동 | 학기, 기간 | 변동 종류, 전후 상태, 효력일, 처리 상태 |
| 강좌별 수강 인원 | 학기, 조직 | 강좌, 담당 교원, 정원, 수강, 대기 |
| 학기 미수강 학생 | 학기, 조직 | 그 학기에 수강이 없는 재학생 |

보이는 범위는 조회자의 권한 범위와 같다(학적 조회 범위 등). 레거시의 수수료·등록금 보고서(학비 미납 등)는 범위 밖이라 없다.

## reporting 뷰

보고서는 DB의 `reporting` 스키마 뷰를 읽는다. BI 도구나 SQL 사용자는 읽기 전용 역할 `app_reporting`으로 같은 뷰를 조회한다.

| 뷰 | 내용 |
|---|---|
| `reporting.students` | 학적 + 인물 이름 + 과정·조직 이름 |
| `reporting.headcount` | 조직·과정·학년·상태별 인원 |
| `reporting.term_records` | 학기별 성적 요약 |
| `reporting.course_grades` | 과목별 성적(확정 여부, 등급, 합격, 재수강) |
| `reporting.section_enrollments` | 강좌별 수강·대기 인원, 담당 교원 |
| `reporting.section_meetings` | 강의 시간과 강의실 |
| `reporting.status_changes` | 학적 변동 |
| `reporting.degree_audits` | 학생·이수 구분별 최신 졸업 요건 점검 |

- 번역 칼럼(`program_name` 등)은 세션 로케일을 따른다: `SET app.locale = 'ko';`. 원본 jsonb 칼럼(`program_name_i18n` 등)도 있다.
- 뷰는 `security_invoker`라 조회자의 행 수준 보안이 그대로 적용된다. 학생 계정으로 읽으면 자기 행만 나온다.
- 뷰 정의는 `database/sql/views/reporting.sql`에 있고, 바꾸면 마이그레이션에서 다시 적용한다.

레거시 `AV_*` 뷰(90여 개)는 쓰이지 않아 옮기지 않았다.
