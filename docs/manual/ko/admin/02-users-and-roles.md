# 2. 사용자와 역할

## 개념

| 용어 | 뜻 |
|---|---|
| 권한 | 기능 하나를 쓸 수 있는 자격. 예: `사용자 조회`, `2단계 인증 초기화` |
| 역할 | 권한 묶음. 예: 학적 담당, 학과 조교 |
| 역할 할당 | 사용자에게 역할을 범위와 기간을 정해 주는 것 |
| 범위 | 역할이 적용되는 곳. **전체**, **조직 단위**(대학, 학과 등), **프로그램** |
| 신분 역할 | 지원자, 학생, 졸업생, 교원, 지도교수. 학사 데이터에 따라 자동으로 주어지며 직접 할당할 수 없다 |

업무 담당이 바뀌면 프로그램 수정 없이 역할 구성이나 할당만 바꾸면 된다. 모든 변경은 감사 기록에 남는다.

## 사용자 계정 만들기

1. **사용자와 권한 > 사용자**에서 **만들기**를 누른다.
2. 이름, 이메일, 언어를 입력하고 저장한다.
3. 사용자에게 비밀번호 설정 링크가 이메일로 간다. 관리자는 비밀번호를 알 수 없다.

계정은 삭제하지 않는다. 퇴직 등으로 사용을 멈추려면 사용자 **수정**에서 **활성**을 끈다. 비활성 계정은 로그인할 수 없고 모든 권한이 없어진다.

## 역할 만들기와 수정

1. **사용자와 권한 > 역할**에서 **만들기** 또는 역할의 **수정**을 누른다.
2. **내부 이름**은 영문 소문자와 밑줄로 쓴다(예: `exam_office`). 만든 뒤에는 바꾸지 않는 것이 좋다.
3. **표시 이름**은 언어별로 입력한다. 영어 이름은 필수다. 언어 칸을 비우면 그 언어 이름이 지워진다.
4. **권한**에서 기능별로 체크한다. 저장하면 추가/제거된 권한이 감사 기록에 남는다.

| 역할 종류 | 수정 | 삭제 |
|---|---|---|
| 시스템 역할(시스템 관리자) | 이름만. 권한은 항상 전체 | 불가 |
| 신분 역할 | 표시 이름과 권한. 내부 이름 불가 | 불가 |
| 일반 역할 | 모두 | 현재 할당이 없을 때만 |

## 역할 할당

1. **사용자와 권한 > 사용자**에서 사용자를 열고 아래 **역할 할당** 목록으로 간다.
2. **역할 할당**을 누르고 역할, 범위, 시작/종료(선택), **사유**를 입력한다.
   - 범위가 조직 단위나 프로그램이면 **범위 대상**에서 고른다. 조직 단위를 고르면 그 아래 모든 조직이 포함된다.
   - 시작을 비우면 바로 적용, 종료를 비우면 무기한이다.
3. 할당은 수정하지 않는다. 바꿀 때는 기존 할당을 **할당 종료**(사유 필수)하고 새로 할당한다. 이력이 그대로 남는다.

자기 자신의 할당은 종료할 수 없다(직무 분리). 다른 관리자에게 요청한다.
