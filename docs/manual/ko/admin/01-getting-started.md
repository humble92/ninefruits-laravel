# 1. 시작하기

## 로그인

1. 브라우저에서 `/login`으로 들어간다.
2. 이메일과 비밀번호를 입력하고 **로그인**을 누른다.
3. 2단계 인증을 등록했다면 인증 앱의 6자리 코드 또는 이메일로 받은 코드를 입력한다.
4. 개인 PC라면 **이 기기 기억하기**를 선택할 수 있다. 정해진 기간(기본 30일) 동안 코드 입력을 생략한다. 공용 PC에서는 선택하지 않는다.

비밀번호를 잊었다면 로그인 화면의 **비밀번호를 잊으셨나요?**에서 재설정 링크를 받는다. 로그인 실패가 반복되면 잠시 로그인이 제한된다.

## 포털과 관리 화면

| 화면 | 주소 | 사용자 |
|---|---|---|
| 포털 | `/portal` | 모든 사용자. 내 정보, 보안 설정. 학생/교수 기능은 이후 Phase에서 추가 |
| 관리 화면 | `/admin` | `관리 화면 사용` 권한이 있는 교직원 |

두 화면은 같은 로그인을 쓴다. 관리 화면 오른쪽 위 사용자 메뉴에서 **2단계 인증**(보안 설정)과 **포털**로 이동할 수 있다.

관리 화면 메뉴는 권한에 따라 보인다. 메뉴가 보이지 않으면 시스템 관리자에게 역할 할당을 요청한다.

## 언어

화면 위쪽 언어 선택에서 바꾼다. 로그인한 상태에서 바꾸면 계정에 저장되어 다음 로그인에도 유지된다. 제공 언어는 시스템 관리자가 **설정 > 기관**에서 정한다.
