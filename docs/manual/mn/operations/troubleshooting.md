# Алдааг олж засварлах

- Зориулалт: МТ-ийн ашиглалтын ажилтнууд

| Шинж тэмдэг | Шалгах зүйл |
|---|---|
| Нэвтэрсний дараа шууд аюулгүй байдлын хуудас руу шилжүүлнэ | Хоёр шатлалт баталгаажуулалтын бодлого "заавал" бөгөөд хөнгөлөлтийн хугацаа өнгөрсөн. Хэрэглэгч бүртгүүлмэгц шийдэгдэнэ. Бодлого нь **Тохиргоо > Аюулгүй байдал** хэсэгт байна |
| Удирдлагын самбарт 403 | Хэрэглэгчид `admin_panel.access` эрхтэй хүчинтэй үүргийн оноолт байхгүй. **Хэрэглэгч ба эрх > Хэрэглэгчид > Үүргийн оноолт**-ыг шалгана |
| Цэсийн зүйл харагдахгүй | Үүрэгт тухайн дэлгэцийн эрх (жишээ нь `roles.view`) байхгүй |
| И-мэйлийн код ирэхгүй | Мэйлийн тохиргоо (`MAIL_*`), аюулгүй байдлын үйл явдлууд дахь `И-мэйлийн код илгээсэн` бичлэгүүд, илгээх хязгаар (минутад нэг удаа, цагт тав) |
| Дэлгэц бусдын өгөгдлийг 0 мөр харуулна | Хэвийн байж болно (мөрийн түвшний хамгаалалт). **Өгөгдлийн өөрчлөлтүүд** дэх хэрэглэгчийн баганаас DB сессийн гүйцэтгэгч тохируулагдсан эсэхийг шалгана |
| `permission denied for schema public` | Аппликейшн `app_runtime`-аар DDL хийхийг оролдсон. Миграцыг зөвхөн `php artisan migrate`-ээр (автоматаар `app_migrator` ашиглана) ажиллуулна |
| `Audit records are append-only` | Аудитын хүснэгтийг шинэчлэх эсвэл устгах оролдлого. Энэ хориг нь зориуд хийгдсэн |
| PDF үүсгэж чадахгүй | `php artisan pdf:sample`, Gotenberg-ийн төлөв, `GOTENBERG_URL` |
| Дарааллын ажлууд гацсан | `/horizon` дахь амжилтгүй ажлууд, `php artisan horizon:status`-ыг шалгана |

Хүсэлт тус бүрийг мөрдөх: `X-Request-Id` хариултын толгойн утгаар лог, үйлдлийн бүртгэл, өгөгдлийн өөрчлөлт, аюулгүй байдлын үйл явдлыг хамтад нь хайж болно.
