# Нөөцлөлт ба сэргээлт

- Зориулалт: МТ-ийн ашиглалтын ажилтнууд

## Нөөцлөх зүйлс

| Объект | Арга | Давтамж (зөвлөмж) |
|---|---|---|
| PostgreSQL | `pg_dump -Fc` эсвэл PITR (WAL архивлалт) | Өдөр бүр бүтэн + тасралтгүй WAL |
| Файлын хадгалалт (`storage/app/private` эсвэл S3) | Snapshot эсвэл хувилбартай bucket | DB-тэй адил |
| Орчны тохиргоо ба түлхүүрүүд | Нууц хадгалалт | Өөрчлөлт бүрд |

DB болон файлын хадгалалтыг ижил цэгт сэргээх боломжтой байх ёстой (зураг болон тодорхойлолтын PDF-ийн мета өгөгдөл DB-д байдаг).

## DB нөөцлөх жишээ

```bash
pg_dump -U app_migrator -d sis -Fc -f sis-$(date +%F).dump
```

`app_migrator` бүх схемийг (`public`, `audit`, `reporting`, `util`) эзэмшдэг тул энэ бүртгэлээр нөөцөлнө. Ролиуд (`app_*`) нь кластерын объект тул dump-д ордоггүй. Сэргээх сервер дээр эхлээд [Суулгалт](installation.md)-ын 2-р хэсэгт заасны дагуу ролиудыг үүсгэнэ.

## Сэргээх жишээ

```bash
createdb -U postgres sis_restore
psql -U postgres -d sis_restore -f database/sql/roles/prepare_database.sql
pg_restore -U app_migrator -d sis_restore --no-owner --role=app_migrator sis-2026-10-22.dump
```

## Сэргээх дадлага

Гурван сар тутам тусдаа сервер дээр сэргээж дараахыг шалгана: нэвтрэх, хувийн мэдээллийг тайлах (түлхүүр таарч байгаа эсэх), аудитын бичлэг харах, файл нээх (зураг, PDF).
