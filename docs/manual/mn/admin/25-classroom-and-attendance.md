# 25. Багшийн анги ба ирц

Цэс: багш нар порталын **Миний заах хичээл > Нэрсийн жагсаалт ба ирц**-ыг, оюутнууд порталын **Ирц**-ыг ашиглана. Ажилтнууд **Сургалтын төлөвлөгөө ба бүлэг > Бүлгүүд > Засах** дэлгэцийн доод хэсэг дэх **Хичээлийн цагууд**-ыг ашиглана.

| Хэн | Хийж болох зүйл |
|---|---|
| Томилогдсон багш нар | Нэрсийн жагсаалт (зурагтай) ба CSV, ирцийн хуудас PDF, хичээлийн цаг үүсгэх, нэмэх, цуцлах, ирц оруулах |
| `Бүлэг төлөвлөх (багш, цаг, танхим)` эрхтэй ажилтан (хамрах хүрээнд) | Багш нартай ижил + удирдлагын самбар дахь хичээлийн цагууд |
| `Бүлэг харах` эрхтэй ажилтан (хамрах хүрээнд) | Нэрсийн жагсаалт, ирцийн хуудас, ирц харах |
| Оюутнууд | Өөрийн ирц |

Зарлал, даалгавар, материал зэрэг ангийн боломжуудыг LMS-д үлдээнэ (шилжүүлэх төлөвлөгөөний 12-р хэсэг).

## Хуучин системээс ялгаатай зүйлс

- **Хуучин систем (YUSTIC) ирц бүртгэдэггүй байв.** Түүний "ирцийн хуудас" нь нэрсийн жагсаалтын хажууд хоосон нүднүүд (хувилбараас хамааран 27-оос 34) хэвлэдэг PDF байсан бөгөөд огноо, нийлбэр байгаагүй. Шинэ систем хичээллэх цагаас **хичээлийн цагууд**-ыг үүсгэж, хичээлийн цаг бүрээр ирсэн, хоцорсон, тасалсан, чөлөөтэйг бүртгэх бөгөөд бүртгэл болон нийлбэрийг ирцийн хуудас PDF-д хэвлэнэ.
- **Нэрсийн жагсаалт.** Хуучин системийн багшийн дэлгэц зөвхөн оюутны код, нэрийг харуулдаг байсан (мөн попап цонхонд регистрийн дугаар, хаягийг ил гаргадаг байсан) бөгөөд Excel татах боломжгүй байв. Шинэ систем зөвхөн оюутны код, нэр, зураг, хөтөлбөр, курс, холбоо барих и-мэйлийг харуулж, CSV хэлбэрээр татна. Татан авалтыг аудитын бүртгэлд тэмдэглэнэ.
- **Багш нарын оюутнууддаа хандах эрх.** Багш нар өөрийн бүлгийн оюутнуудын оюутны бүртгэл болон хувь хүний мэдээллийг харах боломжтой болгох RLS бодлого нэмсэн (өмнө нь зөвхөн зөвлөх оюутнуудаа харж чаддаг байсан тул дүн оруулах дэлгэцэд ч нэр хоосон гардаг байв).

## Хичээлийн цагууд

- **Үүсгэх**: долоо хоногийн хичээллэх цагийн (гараг, цаг, пар) давталт бүрт нэг хичээлийн цаг. Багш нар **Хуваарийн цагаас үүсгэх** товчийг; ажилтнууд удирдлагын самбарын **Хичээлийн цагууд > Хичээлийн цаг үүсгэх**-ийг эсвэл `attendance:generate-sessions {term}` командыг (бүтэн улирал) ашиглана. Байгаа хичээлийн цаг болон ирцэд хүрэхгүй тул хичээллэх цаг өөрчлөгдсөний дараа дахин ажиллуулж болно.
- **Хичээлийн цаг нэмэх**: нөхөх хичээл гэх мэт хичээллэх цагаас гадуурх хичээл. Зөвхөн хичээллэх хугацаан доторх огноо.
- **Цуцлах**: шалтгаантайгаар хичээлийн цагийг цуцална. Хичээлийн цаг үлдэх боловч нийлбэрт тооцогдохгүй. **Сэргээх** нь буцаан сэргээнэ.
- Амралтын өдрийн хуанли байхгүй. Нийтийн амралтын өдрүүдийн хичээлийн цагийг цуцална (13.2-р хэсгийг үзнэ үү; улирлын хуанли нэмэгдмэгц автомат болно).

## Ирц оруулах

Хичээлийн цагийн **Ирц** хэсэгт оюутан бүрт ирсэн, хоцорсон, тасалсан эсвэл чөлөөтэйг сонгож, тэмдэглэл (200 тэмдэгт) нэмнэ. Хамгийн хурдан арга нь **Бүгд ирсэн**-ийг дараад онцгой тохиолдлуудыг өөрчлөх юм.

- Ирцийг хичээлийн цагийн өдрөөс эхлэн оруулж болно (ирээдүйн хичээлийн цагт биш).
- Дахин хадгалахад зөвхөн өөрчлөгдсөн оюутнуудыг бүртгэх бөгөөд аудитын үйл явдал (`attendance.recorded`) хуучин ба шинэ утгыг хадгална.
- Төлвийг арилгавал оюутан "Бүртгээгүй" төлөвт буцна.

## Нийлбэр

| Үзүүлэлт | Тодорхойлолт |
|---|---|
| Орсон хичээлийн цаг | Цуцлагдаагүй бөгөөд өнөөдөр эсвэл түүнээс өмнө болсон хичээлийн цагууд |
| Ирцийн хувь | (ирсэн + хоцорсон + чөлөөтэй) ÷ орсон хичээлийн цаг × 100 |
| Бүртгээгүй | Бүртгэлгүй орсон хичээлийн цагууд |

Тодорхой тооны хоцролтыг тасалсанд шилжүүлэх, эсвэл гуравны нэгээс дээш тасалсан бол F өгөх дүрэм байхгүй. Энэ нь их сургууль бүрт өөр тул багш нар ирцийг дүнд өөрсдөө тусгана (хянах зүйл 13.5).

## Ирцийн хуудас PDF ба нэрсийн жагсаалт CSV

Хоёр татан авалт хоёулаа аудитын бүртгэлд тэмдэглэгдэнэ (`attendance.sheet_exported`; нэрсийн жагсаалт CSV өмнөх шиг). `=`, `+`, `-` эсвэл `@`-аар эхэлсэн CSV утгыг томьёо болж ажиллахгүйн тулд урд нь дан хашилт нэмж гаргана.

- **Ирцийн хуудас (PDF)**: хэвтээ A4. Оюутнууд босоо, хичээлийн цагууд хэвтээ (цуцалсныг оруулахгүй), O/△/X/Ч тэмдэг болон оюутан тус бүрийн нийлбэр. Болоогүй хичээлийн цагууд хоосон тул гараар бүртгэхэд ч ашиглаж болно.
- **Нэрсийн жагсаалт (CSV)**: оюутны код, нэр, хөтөлбөр, курс, холбоо барих и-мэйл, хичээлийн бүртгэлийн төлөв. BOM-той UTF-8 тул Excel-д шууд нээгдэнэ. Татан авалт бүр аудитын үйл явдал `attendance.roster_exported`-д тэмдэглэгдэнэ.

## Оюутны портал

**Ирц**: улирал болон хичээл тус бүрээр ирсэн, хоцорсон, тасалсан, чөлөөтэйн тоо, ирцийн хувь, хичээлийн цаг тус бүрийн бүртгэл (зөвхөн багшийн оруулсан).

## Ажиллах журам

1. Улирал эхлэхээс өмнө бүлгүүдийн хичээллэх цагийг эцэслэнэ ([18-р бүлэг](18-sections-and-timetables.md)).
2. `php artisan attendance:generate-sessions {term} --actor=...`-оор хичээлийн цагуудыг үүсгэнэ (багш нар ч дэлгэц дээрээс үүсгэж болно).
3. Хичээллэх цаг өөрчлөгдөхөд дахин ажиллуулна. Хасагдсан цагийн хичээлийн цагууд автоматаар устахгүй; тэдгээрийг цуцална.
