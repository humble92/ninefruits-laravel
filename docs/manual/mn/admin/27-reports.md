# 27. Тайлан ба тайлангийн View-үүд

Цэс: **Тайлан > Тайлан** (`Стандарт тайлан харах, татах` эрх). Үүргийн анхдагч тохиргоо: Оюутны бүртгэл хариуцсан ажилтан, Сургалтын албаны ажилтан, Тэнхимийн туслах ажилтан (хамрах хүрээнд).

## Стандарт тайлан

Тайлан болон шүүлтүүрээ сонгоно: дэлгэцэд 500 хүртэл мөр харагдах бөгөөд **CSV татах** нь бүгдийг нь авна (BOM-той UTF-8, Excel-д шууд нээгдэнэ). Татан авалтыг аудитын үйл явдал `reports.exported`-д тэмдэглэнэ. `=`, `+`, `-` эсвэл `@`-аар эхэлсэн утгыг Excel томьёо болгон ажиллуулахгүйн тулд урд нь дан хашилт (`'`) нэмж гаргана.

| Тайлан | Шүүлтүүр | Агуулга |
|---|---|---|
| Оюутны жагсаалт | Бүтцийн нэгж (доорх нэгжүүдийг оруулан), төлөв, курс | Оюутны код, нэр, хөтөлбөр, бүтцийн нэгж, курс, төлөв, элссэн огноо, төгссөн огноо, дипломын дугаар |
| Нэгж, хөтөлбөр, курс, төлөвөөрх оюутны тоо | Бүтцийн нэгж, төлөв | Оюутны тоо |
| Улирлын дүнгийн нэгтгэл | Улирал, сурлагын байдал | Улирлын болон нийт кредит ба голч дүн, академик сануулгын тоо, онц сурлагын эрэмбэ ([21-р бүлэг](21-grades.md)) |
| Төгсөх оюутнууд | Хангасан эсэх | Оюутан болон хөтөлбөр тус бүрийн хамгийн сүүлийн төгсөлтийн шалгалт ([26-р бүлэг](26-graduation.md)) |
| Шилжилт хөдөлгөөн | Улирал, хугацаа | Өөрчлөлтийн төрөл, өмнөх ба дараах төлөв, хүчин төгөлдөр болох огноо, хүсэлтийн төлөв |
| Бүлэг тус бүрийн бүртгэл | Улирал, бүтцийн нэгж | Бүлэг, багш нар, суудлын тоо, бүртгүүлсэн, хүлээж буй |
| Улиралд хичээл сонгоогүй оюутнууд | Улирал, бүтцийн нэгж | Тухайн улиралд хичээлийн бүртгэлгүй суралцаж буй оюутнууд |

Харагдах зүйл нь харж буй хүний эрхийн хамрах хүрээг (оюутны бүртгэл харах хамрах хүрээ гэх мэт) дагана. Хуучин системийн (YUSTIC) төлбөр, сургалтын төлбөрийн тайлангууд (сургалтын төлбөр төлөөгүй гэх мэт) хамрах хүрээнээс гадуур бөгөөд байхгүй.

## reporting view-үүд

Тайлангууд өгөгдлийн сангийн `reporting` схемийн view-үүдийг уншина. BI хэрэгсэл болон SQL хэрэглэгчид зөвхөн унших эрхтэй `app_reporting` үүргээр ижил view-үүдэд хандана.

| View | Агуулга |
|---|---|
| `reporting.students` | Оюутны бүртгэл + хувь хүний нэр + хөтөлбөр ба бүтцийн нэгжийн нэр |
| `reporting.headcount` | Бүтцийн нэгж, хөтөлбөр, курс, төлөвөөрх оюутны тоо |
| `reporting.term_records` | Улирал тус бүрийн дүнгийн нэгтгэл |
| `reporting.course_grades` | Хичээл тус бүрийн дүн (баталгаажсан эсэх, дүн, тэнцсэн, давтан судалсан) |
| `reporting.section_enrollments` | Бүлэг тус бүрийн бүртгүүлсэн болон хүлээж буй, багш нар |
| `reporting.section_meetings` | Хичээллэх цаг ба танхим |
| `reporting.status_changes` | Шилжилт хөдөлгөөн |
| `reporting.degree_audits` | Оюутан болон хөтөлбөрийн төрөл тус бүрийн хамгийн сүүлийн төгсөлтийн шалгалт |

- Орчуулсан баганууд (`program_name` гэх мэт) сессийн locale-ийг дагана: `SET app.locale = 'ko';`. Түүхий jsonb баганууд (`program_name_i18n` гэх мэт) ч бас бий.
- View-үүд `security_invoker` тул харж буй хүний мөрийн түвшний аюулгүй байдал (RLS) өөрчлөлтгүй үйлчилнэ. Оюутны бүртгэлээр уншвал зөвхөн тухайн оюутны мөрүүдийг буцаана.
- View-үүдийн тодорхойлолт `database/sql/views/reporting.sql`-д байна; өөрчилсний дараа migration-аас дахин хэрэгжүүлнэ.

Хуучин системийн `AV_*` view-үүд (90 орчим) ашиглагдаагүй байсан тул шилжүүлээгүй.
