# Talabalar axborot tizimi qoʻllanmasi (Oʻzbekcha)

Tizimni har kuni boshqaradigan xodimlar hamda uni oʻrnatadigan, joriy etadigan va xizmat koʻrsatadigan IT operatorlari uchun. Ekranlar oʻzbek tilida mavjud (foydalanuvchi menyusi > til).

Boshqa tillar: [한국어](../ko/README.md), [English](../en/README.md), [简体中文](../zh_CN/README.md), [ລາວ](../lo/README.md), [Deutsch](../de/README.md), [Filipino](../fil/README.md), [Français](../fr/README.md), [日本語](../ja/README.md), [Монгол](../mn/README.md), [Bahasa Melayu](../ms/README.md), [नेपाली](../ne/README.md), [Русский](../ru/README.md), [ไทย](../th/README.md), [Türkçe](../tr/README.md), [Tiếng Việt](../vi/README.md). Asl manba koreys tilidagi nashr; qolgan nashrlar ona tili sohiblari tomonidan tekshirilishi kutilayotgan tarjimalardir.
