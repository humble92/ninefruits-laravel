# 23. Справки

Меню: **Справки > Выданные справки**, **Виды справок**, **Настройки > Настройки справок**. Справки выдаются кнопкой **Выдать справку** на экране личного дела студента (**Студенты и сотрудники > Личные дела студентов > Просмотр**). Студенты скачивают PDF-файлы своих справок на портале в разделе **Справки**. Любой может проверить справку на странице `/verify/{code}`.

| Разрешение | Что позволяет |
|---|---|
| `Выдавать, формировать заново и аннулировать справки` | Выдача, повторное формирование, аннулирование, просмотр выданных справок (в пределах области действия просмотра личных дел студентов) |
| `Управлять видами справок, шаблонами и настройками` | Виды справок и их шаблоны для каждого языка, шаблон регистрационного номера, подписанты |

Роли по умолчанию: ответственный за справки выдаёт справки, у сотрудника учебного отдела (Registrar) есть оба разрешения, сотрудник учебного управления (Academic Affairs) управляет видами и шаблонами.

## Отличия от прежней системы

- **Журнал выданных справок.** Прежняя система (YUSTIC) печатала прямо с экрана (`aca3/cti_*`), а её журнал (`SRCERT`) существовал только для генерации номеров, поэтому по нему нельзя было узнать, кто выдал справку и не была ли она аннулирована. Новая система при каждой выдаче записывает регистрационный номер, код проверки, сотрудника, цель, число экземпляров, PDF-файл и контрольную сумму, а аннулированная справка сохраняет свою строку.
- **Проверка.** В прежней системе её не было. Каждая справка содержит код проверки и QR-код, а общедоступная страница показывает факт выдачи, вид справки, дату выдачи и замаскированные данные владельца (первая и последняя буквы фамилии и имени, первые 4 цифры студенческого номера).
- **Шаблоны.** В прежней системе для каждого вида и языка был отдельный PDF-скрипт. Новая система позволяет редактировать на экране шаблон для каждого языка (заголовок, текст, нижний колонтитул, подписант) у каждого вида справки.
- **Запреты.** Прежняя система выдавала справки независимо от списка запретов на запись. Новая система не выдаёт справки студенту с запретом выдачи справок ([глава 20](20-registration.md)).
- Оплата не учитывается (прежняя система записывала только сумму).
- Онлайн-заказа справок студентами нет (план переноса 17.5). Справки выдают сотрудники.

## Виды и шаблоны

**Виды справок**: код (используется в регистрационном номере), название (3 языка), для кого (любое личное дело / студенты / выпускники), с оценками, с фотографией, активен, порядок. Профиль корейского университета создаёт три вида.

| Код | Вид | Для кого | Примечание |
|---|---|---|---|
| `ENR` | Справка об обучении | Студенты (не выпускники) | |
| `GRD` | Справка об окончании | Выпускники | Дата выпуска, номер диплома |
| `TRN` | Академическая справка | Любое личное дело | Таблица итоговых оценок по семестрам, накопленный средний балл и полученные кредиты |

**Шаблоны** (внизу экрана редактирования вида): по одному на язык. Заголовок, текст (абзацы разделяются пустой строкой), нижний колонтитул, подписант. В тексте используются подстановки в фигурных скобках.

| Подстановка | Значение |
|---|---|
| `{institution}` | Название учебного заведения (на этом языке) |
| `{student_name}`, `{student_number}` | ФИО (в форме для этого языка, иначе латиницей), студенческий номер |
| `{program}`, `{org_unit}` | Программа, подразделение |
| `{admission_date}`, `{graduation_date}`, `{degree_number}` | Дата зачисления, дата выпуска, номер диплома |
| `{status}`, `{year_level}` | Статус студента, курс |
| `{birth_date}`, `{gender}`, `{nationality}` | Дата рождения, пол, гражданство |
| `{issue_date}`, `{serial_number}`, `{purpose}`, `{copies}` | Дата выдачи, регистрационный номер, цель, число экземпляров |

Даты печатаются в формате этого языка. Отсутствующее значение (например, дата выпуска) печатается пустым. Над текстом автоматически добавляется таблица личных данных (ФИО, студенческий номер, дата рождения, пол, гражданство, программа, дата зачисления, затем дата выпуска для выпускников или статус и курс для остальных).

## Настройки

**Настройки > Настройки справок**

- **Шаблон регистрационного номера**: по умолчанию `{TYPE}-{YYYY}-{SEQ:6}` → `ENR-2026-000001`. `{SEQ:n}` обязателен. Нумерация ведётся отдельно для каждого отличающегося префикса. `{TYPE}-{SEQ:6}` нумерует по видам сквозь годы, `{YYYY}{SEQ:5}` — по годам для всех видов. Одновременные выдачи никогда не конфликтуют (счётчик атомарно увеличивается в базе данных).
- **Срок проверки (дней)**: 0 — без ограничения. По истечении срока страница проверки отвечает «срок истёк». Сама выдача остаётся в журнале.
- **Подписант по языкам**: имя, печатаемое над печатью («Ректор Университета Ninefruits»). Подписант, указанный в шаблоне, имеет приоритет.

## Выдача

**Выдать справку** на экране личного дела студента: вид, язык, цель, число экземпляров (от 1 до 20). При сохранении PDF открывается в новой вкладке.

В выдаче отказывается, если:

- вид справки не подходит по адресату (справка об обучении для выпускника, справка об окончании для обучающегося студента)
- вид справки неактивен
- для этого языка нет шаблона
- для студента действует **запрет выдачи справок** (ограничение, [глава 20](20-registration.md)); сначала снимите его
- личное дело студента вне области действия просмотра

Выдача записывается в журнал действий (`certificate.issued`: студенческий номер, вид, язык, регистрационный номер, число экземпляров, цель).

## Выданные справки

**Справки > Выданные справки**: дата выдачи, регистрационный номер, вид и язык, студенческий номер, ФИО, цель, число экземпляров, статус, сотрудник. Фильтр по виду и статусу. Область действия просмотра такая же, как для личных дел студентов.

- **PDF**: открывает сохранённый файл. Он не формируется заново, поэтому в точности соответствует выданному.
- **Страница проверки**: открывает общедоступную страницу.
- **Сформировать заново**: формирует новый PDF по текущим данным, например после исправления шаблона, и заменяет файл. Регистрационный номер и код проверки сохраняются; контрольная сумма меняется. Событие аудита `certificate.rerendered`. То же, что команда `certificate:render`.
- **Аннулировать**: требуется причина. Строка и файл сохраняются, статус становится «аннулирована», а страница проверки отвечает «аннулирована». Событие аудита `certificate.revoked`. Аннулированная справка не восстанавливается; выдаётся новая.

Строки журнала нельзя редактировать или удалять на экране.

## Проверка

- URL проверки (`/verify/{code}`) и QR-код печатаются внизу справки. Код — случайная строка из 20 символов.
- Страница открывается без входа и ограничена 30 запросами в минуту. Она показывает, выдавалась ли справка, её вид, регистрационный номер, дату выдачи, а также замаскированные ФИО и студенческий номер. Для аннулированных, просроченных и неизвестных кодов выводятся разные ответы.
- Чтобы проверить сам представленный PDF-файл, сравните контрольную сумму (SHA-256) в журнале с хешем файла. Это же делает команда `certificate:verify {code}`.

## Портал студента

**Справки**: справки, выданные по собственному личному делу студента, с PDF-файлами. Аннулированные справки показываются в списке со своим статусом, но скачать PDF аннулированной справки студент не может (выдавший сотрудник может открыть его для проверки записи). Файлы других студентов открыть нельзя (это обеспечивают приложение и база данных).

## Частые вопросы

- **Имя написано неправильно.** Исправьте вариант имени лица (на этом языке) и нажмите **Сформировать заново**. Если справка уже передана, аннулируйте её и выдайте новую.
- **Я изменил шаблон; что будет с уже выданными справками?** Они не меняются. При необходимости используйте **Сформировать заново**.
- **Регистрационный номер пропущен.** Если при выдаче происходит ошибка (например, недоступен сервис PDF), номер расходуется, а строка журнала может не остаться. Гарантируется уникальность номеров, но не их непрерывность.
