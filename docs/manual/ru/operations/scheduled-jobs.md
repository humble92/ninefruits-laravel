# Задания по расписанию и очереди

- Для кого: ИТ-специалисты по эксплуатации

## Постоянно работающие процессы

| Процесс | Команда | Проверка |
|---|---|---|
| Обработчик очереди | `php artisan horizon` | `/horizon` (разрешение `queue_monitor.view`) |
| Планировщик | cron `* * * * * php artisan schedule:run` | `php artisan schedule:list` |

## Задания по расписанию

Каждый этап дополняет эту таблицу. Регистрация заданий находится в `routes/console.php`. Время указано в часовом поясе сервера (UTC).

| Задание | Периодичность | Этап | Обнаружение сбоев |
|---|---|---|---|
| `admission:expire-drafts` | Ежедневно в 03:10 | 3 | Каждый запуск записывается в журнал действий (журнал `command`). Если записи нет более суток, проверьте планировщик |
| `registration:release-reserved-seats` | Каждые 5 минут | 5 | Записи аудита нет. Если у распределений мест с прошедшим временем освобождения `release_processed_at` всё ещё пуст, проверьте планировщик |
| `waitlist:promote` | Ежечасно | 5 | Каждый запуск записывается в журнал действий (журнал `command`) |

## Задания очереди

| Задание | Чем запускается | Примечания |
|---|---|---|
| `ReencryptPiiRecords` | `pii:reencrypt` | Пакет. Неудавшиеся задания перезапускайте из Horizon |
| `PromoteWaitlistJob` | Отмена записи или выход из дисциплины, освобождение распределённого места | Для одной группы одновременно выполняется только одно задание (дубликаты исключены). При продвижении листа ожидания все правила проверяются заново |
| `CloseTermRecordsJob`, `FinishTermCloseJob` | `term:close`, закрытие семестра в панели администрирования | Пакеты по 100 студентов, затем завершающее задание (рейтинг отличия, смена статуса семестра). Ход выполнения отслеживайте в пакете Horizon `term-close:{term code}`. Неудавшиеся задания перезапускайте из Horizon (расчёты по каждому студенту при повторном запуске дают тот же результат) |
| `ImportCsv` (Filament) | Импорт CSV в панели администрирования, `reference:import` | Пакет. О завершении сообщается уведомлением в панели администрирования (таблица `notifications`). Неудавшиеся строки попадают в `failed_import_rows` |
| `audit:seal` | Ежедневно в 03:30 | Запечатывает хеш-цепочку аудита ([Целостность аудита](audit-and-maintenance.md)) |
| Сигнал активности планировщика | Каждую минуту | Записывает время последнего запуска в кеш. `system:health-check` считает сбоем отсутствие сигнала более 5 минут |

Во время выполнения задания очереди исполнитель в БД записывается как `system:job:{class}`.
