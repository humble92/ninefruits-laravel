# トラブルシューティング

- 対象読者: IT 運用担当者

| 症状 | 確認すること |
|---|---|
| ログイン直後にセキュリティのページへリダイレクトされる | 二要素認証のポリシーが「必須」で、猶予期間が過ぎています。ユーザーが登録すれば解消します。ポリシーは **設定 > セキュリティ** にあります |
| 管理画面で 403 になる | ユーザーに `admin_panel.access` 権限を持つ有効なロール割り当てがありません。**ユーザーとアクセス > ユーザー > ロール割り当て** を確認してください |
| メニュー項目が表示されない | ロールにその画面の権限(例: `roles.view`)がありません |
| メールのコードが届かない | メール設定(`MAIL_*`)、セキュリティイベントのうち `メールのコードを送信` のエントリ、送信制限(1 分に 1 回、1 時間に 5 回) |
| 画面に他の人のデータが 0 件と表示される | 正常な場合があります(行レベルセキュリティ)。**データ変更履歴** のユーザー列を見て、DB セッションの実行者が設定されていることを確認してください |
| `permission denied for schema public` | アプリケーションが `app_runtime` で DDL を試みました。マイグレーションは必ず `php artisan migrate`(自動的に `app_migrator` を使用)で実行してください |
| `Audit records are append-only` | 監査テーブルを更新または削除しようとしました。この遮断は意図されたものです |
| PDF の生成に失敗する | `php artisan pdf:sample`、Gotenberg の状態、`GOTENBERG_URL` |
| キュージョブが滞留している | `/horizon` で失敗したジョブを確認、`php artisan horizon:status` |

リクエスト単位の追跡: レスポンスヘッダー `X-Request-Id` の値で、ログ、業務ログ、データ変更履歴、セキュリティイベントをまとめて検索できます。
