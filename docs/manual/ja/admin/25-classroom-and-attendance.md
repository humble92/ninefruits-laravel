# 25. 教員の授業運営と出欠

メニュー: 教員はポータルの **担当授業 > 名簿と出欠** を、学生はポータルの **出欠** を使います。職員は **教育課程・開講科目 > 開講科目 > 編集** 画面の下部にある **授業回** を使います。

| 利用者 | できること |
|---|---|
| 割り当てられた教員 | 履修者名簿(写真付き)と CSV、出席簿 PDF、授業回の生成・追加・休講、出欠の入力 |
| `開講科目の編成(教員・時間・教室)` 権限を持つ職員(範囲内) | 教員と同じ + 管理画面での授業回 |
| `開講科目の閲覧` 権限を持つ職員(範囲内) | 履修者名簿、出席簿、出欠の閲覧 |
| 学生 | 自分の出欠 |

お知らせ、課題、資料などの授業運営の機能は LMS に任せます(移行計画 第 12 節)。

## 旧システムとの違い

- **旧システム(YUSTIC)は出欠を記録していませんでした。** その「出席簿」は、名簿の横に空欄のマス(帳票によって 27〜34 個)を印刷しただけの PDF で、日付も集計もありませんでした。新システムでは授業時間から **授業回** を作成し、授業回ごとに出席・遅刻・欠席・公欠を記録して、記録と集計を出席簿 PDF に出力します。
- **履修者名簿。** 旧システムの教員画面は学籍番号と氏名しか表示せず(しかもポップアップで住民登録番号と住所が見えていました)、Excel でのダウンロードもできませんでした。新システムでは学籍番号、氏名、写真、プログラム、学年、連絡用メールアドレスだけを表示し、CSV でダウンロードできます。ダウンロードは監査ログに記録されます。
- **教員による担当学生へのアクセス。** 教員が担当開講科目の学生の学籍と人物を閲覧できるよう、RLS ポリシーを追加しました(以前は指導学生しか見えず、成績入力画面でさえ氏名が空欄になっていました)。

## 授業回

- **生成**: 毎週の授業時間(曜日、時間、時限)の各回につき 1 つの授業回を作成します。教員は **授業時間から生成** ボタンを、職員は管理画面の **授業回 > 授業回を生成** またはコマンド `attendance:generate-sessions {term}`(学期全体)を使います。既存の授業回と出欠には手を加えないため、授業時間を変更した後に再実行できます。
- **授業回を追加**: 補講など、授業時間以外の授業。授業期間内の日付に限ります。
- **休講にする**: 理由を付けて授業回を休講にします。授業回は残りますが、集計からは除外されます。**元に戻す** で元に戻せます。
- 祝日カレンダーはありません。祝日の授業回は休講にしてください(13.2 節を参照。学期カレンダーが追加されれば自動化されます)。

## 出欠の入力

授業回の **出欠入力** で、学生ごとに出席・遅刻・欠席・公欠を選び、備考(200 文字)を追加します。最も早いのは、**全員出席** を押してから例外だけを変更する方法です。

- 出欠は授業当日から入力できます(未来の授業回には入力できません)。
- 再度保存すると変更のあった学生だけが記録され、監査イベント(`attendance.recorded`)には変更前後の値が残ります。
- 出欠区分を消去すると、その学生は「未記録」に戻ります。

## 集計

| 項目 | 定義 |
|---|---|
| 実施済み授業回 | 休講ではなく、今日以前の授業回 |
| 出席率 | (出席 + 遅刻 + 公欠)÷ 実施済み授業回 × 100 |
| 未記録 | 記録のない実施済み授業回 |

遅刻の回数を欠席に換算したり、欠席が 3 分の 1 を超えたら F にしたりする規則はありません。大学によって異なるため、教員が自ら出欠を成績に反映します(検討項目 13.5)。

## 出席簿 PDF と履修者名簿 CSV

どちらのダウンロードも監査ログに記録されます(`attendance.sheet_exported`。履修者名簿 CSV は従来どおり)。`=`、`+`、`-`、`@` で始まる CSV の値は、数式として実行されないよう先頭にシングルクォートを付けて出力されます。

- **出席簿(PDF)**: A4 横。縦に学生、横に授業回(休講は除外)を並べ、○/△/×/公 の記号と学生ごとの集計を表示します。これからの授業回は空欄なので、手書きでの記録にも使えます。
- **履修者名簿(CSV)**: 学籍番号、氏名、プログラム、学年、連絡用メールアドレス、履修状態。BOM 付きの UTF-8 なので、そのまま Excel で開けます。すべてのダウンロードは監査イベント `attendance.roster_exported` に記録されます。

## 学生ポータル

**出欠**: 学期・科目ごとの出席・遅刻・欠席・公欠の回数、出席率、授業回ごとの記録(教員が入力したもののみ)。

## 運用手順

1. 学期が始まる前に、開講科目の授業時間を確定します([第 18 章](18-sections-and-timetables.md))。
2. `php artisan attendance:generate-sessions {term} --actor=...` で授業回を作成します(教員も画面で作成できます)。
3. 授業時間が変わったら再実行します。削除した時間の授業回は自動的には削除されないため、休講にしてください。
